Create `apps/web/scripts/audit/db-tenant-audit.ts`. The script must:

**Import**
```ts
import { PrismaClient } from '../src/generated/prisma/client';
import * as fs from 'fs';
import * as path from 'path';
```
Instantiate PrismaClient normally (DATABASE_URL is read from env via --env-file).

**Step 1 — collect all public-schema tables**
```sql
SELECT table_name
FROM information_schema.tables
WHERE table_schema = 'public' AND table_type = 'BASE TABLE'
ORDER BY table_name;
```
Use `prisma.$queryRawUnsafe(sql)` for every query (read-only SELECT only — no DML whatsoever).

**Step 2 — collect columns for every table (one query)**
```sql
SELECT table_name, column_name, data_type, udt_name
FROM information_schema.columns
WHERE table_schema = 'public'
ORDER BY table_name, column_name;
```
Build a Map: tableName → Set of column names, and a separate Map: tableName → Map of columnName → data_type/udt_name.

**Step 3 — collect RLS flags (one query)**
```sql
SELECT
  c.relname AS table_name,
  c.relrowsecurity AS rls_enabled,
  c.relforcerowsecurity AS rls_forced
FROM pg_class c
JOIN pg_namespace n ON n.oid = c.relnamespace
WHERE n.nspname = 'public' AND c.relkind = 'r';
```
Build a Map: tableName → { rlsEnabled: boolean, rlsForced: boolean }.

**Step 4 — collect RLS policies (one query)**
```sql
SELECT
  schemaname,
  tablename,
  policyname
FROM pg_policies
WHERE schemaname = 'public';
```
Build a Map: tableName → Set of policy names.
A table `has_tenant_isolation_policy` = any policy name ILIKE '%tenant_isolation%'.
A table `has_bypass_rls_policy` = any policy name ILIKE '%bypass_rls%'.

**Step 5 — collect indexes (one query)**
```sql
SELECT
  t.relname AS table_name,
  ix.relname AS index_name,
  array_agg(a.attname ORDER BY k.ordering) AS columns
FROM pg_class t
JOIN pg_index i ON i.indrelid = t.oid
JOIN pg_class ix ON ix.oid = i.indexrelid
JOIN pg_namespace n ON n.oid = t.relnamespace
JOIN LATERAL unnest(i.indkey) WITH ORDINALITY AS k(attnum, ordering) ON true
JOIN pg_attribute a ON a.attrelid = t.oid AND a.attnum = k.attnum
WHERE n.nspname = 'public' AND t.relkind = 'r'
GROUP BY t.relname, ix.relname
ORDER BY t.relname, ix.relname;
```
Build a Map: tableName → Array of { indexName: string, columns: string[] }.

**Step 6 — per-table analysis**

For each table, compute:

`hasTenantId`: columns has 'tenant_id' (standard tables) OR columns has 'org_id' (carrier tables).

`isTenantScoped`: hasTenantId (direct) OR table has no tenant_id but is one of the known junction/leaf tables that are reachable via FK — detect this by checking if columns includes a FK column that points to a tenant-scoped parent. For the purposes of this script, treat it as: `hasTenantId` = true when org_id or tenant_id is present. Tables with neither but which are listed in the schema are "indirectly scoped" if they appear to be junction tables (check: does the table have columns that end in '_id' pointing to tables that themselves have tenant_id). Use a simple heuristic: if the table has tenant_id or org_id → directly scoped (Y). If not, check if the table is a known junction table by looking for at least one FK column to a table that IS directly scoped — for this check, use the already-loaded column set: if any column name matches `{parentTable}_id` and that parentTable is in the directly-scoped set, mark is_tenant_scoped = Y (reachable via FK). Otherwise N.

`hasRlsEnabled`, `hasRlsForced`: from Step 3 map.
`hasTenantIsolationPolicy`, `hasBypassRlsPolicy`: from Step 4 map.

Audit columns (each Y/N):
- `hasCreatedAt`: columns has 'created_at'
- `hasCreatedBy`: columns has 'created_by'
- `hasUpdatedAt`: columns has 'updated_at'
- `hasUpdatedBy`: columns has 'updated_by'
- `hasDeletedAt`: columns has 'deleted_at'
- `hasDeletedBy`: columns has 'deleted_by'

`timestampColumnTypes`: list all columns whose udt_name is 'timestamp' (i.e., timestamp WITHOUT time zone). Format as comma-separated column names, or '-' if none.

`missingIndexes`: per Section 5.2 of the spec. Only check tenant-scoped tables (is_tenant_scoped = Y). For each:
- Missing `(tenant_id)` single: check if indexes map contains any index whose columns array equals ['tenant_id'] or ['org_id'] (for carrier tables).
- Missing `(tenant_id, deleted_at)`: only if deleted_at column exists. Check if any index has columns ['tenant_id','deleted_at'] or ['org_id','deleted_at'] in that order (or either order since b-tree covers both).
- Missing `(tenant_id, created_at desc)`: only if created_at column exists. Check if any index has columns including both tenant_id/org_id and created_at (order doesn't matter for presence check, just confirm both columns appear together in one index).
Collect names of missing required indexes as a comma-separated string, or '-' if all present.
