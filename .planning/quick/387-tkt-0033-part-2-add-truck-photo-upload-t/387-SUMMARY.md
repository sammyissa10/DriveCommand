# Quick Task 387: TKT-0033 Part 2 — Truck Photo Upload Summary

## Approach (3-4 sentences)

The migration adds a nullable `photo_s3_key TEXT` column to `carrier_trucks` via `20260520000001_add_carrier_truck_photo_s3_key`. The `photoS3Key` data path flows from the Prisma-generated `CarrierTruck` model → `getCarrierTruck()` service → page prop `photoS3Key={truck.photoS3Key}` → `CarrierTruckDetailClient` → cast `TruckWithPhoto` in `CarrierTruckDetailsView` → `TruckPhotoSection` component that fetches `GET /photo-view-url` on mount. Signed display URLs are generated by calling the existing `generateDownloadUrl(s3Key)` helper from `apps/web/src/lib/storage/presigned.ts`, which uses `GetObjectCommand` + `getSignedUrl` with a 1-hour expiry and `ResponseContentDisposition: 'inline'`. The `TruckPhotoUploadModal` mirrors `DocumentUploadModal`'s presign→PUT→PATCH pattern but strips document-type selection and notes, uses `fetch` instead of XHR, and limits to JPEG/PNG/WebP under 5MB.

