## Step 3: reconciliation against the quick-616 census

**For this sweep's class:** the census counted **0 of the 3** layout statements.

**What its method could not see.** `616-bypass-census.ts`'s unit is "the INNERMOST CallExpression/
TaggedTemplateExpression whose own literal children contain `app.bypass_rls`". It counts the **flag**, not the
**query**. Its surface rules already enumerate `src/app/(owner)/**`, so the layout was *in scope by path*. It
yielded nothing because the three reads never set the flag. **The blind spot is not a file type. It is every
tenant-table query on the bare client that does not carry the literal, in any file kind.** Layouts are simply
the highest-traffic place it happened to surface.

**The class, measured** (`621-bare-client-inventory.ts`, `03-bare-client-inventory-before.json`). Units are rooted
at the imported `prisma` identifier, each `$transaction` counts as one unit, tables are resolved via `@@map` plus
the raw-SQL `FROM/JOIN/INTO/UPDATE`, and RLS state was measured on staging.
