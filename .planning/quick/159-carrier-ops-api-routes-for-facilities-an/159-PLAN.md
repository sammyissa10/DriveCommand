Helper `computeNextOccurrence(recurrenceRule: string, timezone: string): string | null`:
- Parse iCal RRULE string. Support these patterns:
  - `FREQ=DAILY;INTERVAL=N` — every N days

  - `FREQ=MONTHLY;BYMONTHDAY=1,15;INTERVAL=N` — specific days of month
- Parse UNTIL or COUNT if present (UNTIL = stop date, COUNT = max occurrences).
- From today forward, find the next date that matches the rule. Return ISO date string or null if rule is exhausted/unparseable.
- Keep this lightweight — no external RRULE library. If the rule is too complex to parse, return null and log a warning.

Create `apps/web/src/lib/carrier/dispatch-generator.ts`:
- Import `prisma` from `@/lib/db/prisma` and `logger` from `@/lib/logger`.
- Export interface `GenerationResult`: `{ dispatchesCreated: number, skippedExisting: number, errors: string[] }`.

Export async function `generateDispatches(orgId: string, templateId: string, generateThroughDate: string): Promise<GenerationResult>`:

1. **Load template**: `prisma.routeTemplate.findFirst({ where: { id: templateId, orgId, active: true }, include: { stops: { orderBy: { sequenceOrder: 'asc' }, include: { facility: true } }, contract: true } })`. If not found, throw error.

2. **Evaluate recurrence rule**: Use `expandSchedule(template.recurrenceRule, template.recurrenceTimezone, today, generateThroughDate)` helper. This returns an array of ISO date strings for each scheduled dispatch date.

   Helper `expandSchedule(rule, timezone, fromDate, toDate)`: Parse the RRULE (reuse similar logic to computeNextOccurrence but expand all dates in range). Support FREQ=DAILY, FREQ=WEEKLY with BYDAY, FREQ=MONTHLY with BYMONTHDAY. Return `string[]` of ISO dates.

3. **Check existing dispatches**: For each scheduled date, check if a dispatch already exists: `prisma.carrierDispatch.findFirst({ where: { routeTemplateId: templateId, orgId, scheduledDeparture: { gte: dayStart, lt: dayEnd } } })`. If exists, increment `skippedExisting` and continue.

4. **For each new dispatch date**:
   a. **Conflict detection**: If `defaultDriverId` or `defaultTruckId` is set on template, check if that driver/truck has another dispatch on the same day. If conflict found, store a note about needing assignment. Since CarrierDispatch has no `needsAssignment` boolean, record in `notes` field: `"[AUTO-GENERATED] needs_assignment=true"` when conflicts exist, or `"[AUTO-GENERATED]"` when no conflicts.

   b. **Generate dispatch number**: Query `SELECT COUNT(*) FROM dispatches WHERE org_id = $orgId AND notes LIKE '[AUTO-GENERATED]%'` to get count, then format as `DC-YYYY-NNNNN` (year + zero-padded sequential). Store the dispatch number in notes as well: `"[AUTO-GENERATED] dispatch_number=DC-2026-00001"`. NOTE: This is a workaround because the schema lacks `dispatchNumber` and `isAutoGenerated` columns. Add a prominent code comment explaining this and recommending migration to add proper columns.

   c. **Create dispatch**: `prisma.carrierDispatch.create({ data: { orgId, routeTemplateId: templateId, primaryDriverId: template.defaultDriverId (REQUIRED — if null, log error and skip this date), truckId: template.defaultTruckId (REQUIRED — if null, log error and skip this date), scheduledDeparture: scheduledDate with scheduledDepartureTime applied, status: 'planned', plannedMiles: template.estimatedMiles as Decimal, notes: autoGenNotes } })`. If defaultDriverId or defaultTruckId is null, add to errors and skip (these are required FK on CarrierDispatch).

   d. **Clone stops**: For each `RouteTemplateStop` on the template, create a `CarrierStop`: `prisma.carrierStop.create({ data: { dispatchId: newDispatch.id, sequenceOrder: stop.sequenceOrder, stopType: stop.stopType, facilityId: stop.facilityId, contactName: stop.contactName, contactPhone: stop.contactPhone, commodityDescription: stop.commodityDescription, specialInstructions: stop.specialInstructions, notes: JSON.stringify({ address_snapshot: { address_line1: stop.facility.addressLine1, city: stop.facility.city, state: stop.facility.state, zip: stop.facility.zip, lat: stop.facility.latitude, lng: stop.facility.longitude } }) } })`. Add code comment: `// address_snapshot stored in notes as JSON — facility data at time of generation. This snapshot NEVER mutates even if the facility record is later updated.`

   e. **Create load if contract**: If template has `contractId`, create a `CarrierLoad`: `prisma.carrierLoad.create({ data: { orgId, dispatchId: newDispatch.id, contractId: template.contractId, clientId: template.clientId, rateType: template.contract.rateType, rateAmount: template.contract.baseRate, fuelSurcharge: compute from contract.fuelSurchargeRate if method != 'none', commodityDescription: template.commodityDescription, status: 'assigned' } })`.

   f. Increment `dispatchesCreated`.

5. **Return** `{ dispatchesCreated, skippedExisting, errors }`.

Wrap the entire per-date logic in try/catch — on error, push to `errors` array and continue to next date.
