    **prisma/migrations/20260311000001_add_sysadmin_invoices/migration.sql** — Create this directory and file:

    ```sql
    -- Create SysAdminInvoiceStatus enum
    CREATE TYPE "SysAdminInvoiceStatus" AS ENUM ('DRAFT', 'SENT', 'PAID', 'OVERDUE', 'VOID');

    -- Create SysAdminInvoice table
    CREATE TABLE "SysAdminInvoice" (
      "id"            UUID NOT NULL DEFAULT gen_random_uuid(),
      "tenantId"      UUID NOT NULL,
      "invoiceNumber" TEXT NOT NULL,
      "status"        "SysAdminInvoiceStatus" NOT NULL DEFAULT 'DRAFT',
      "issueDate"     TIMESTAMPTZ NOT NULL,
      "dueDate"       TIMESTAMPTZ NOT NULL,
      "subtotal"      DECIMAL(12,2) NOT NULL,
      "total"         DECIMAL(12,2) NOT NULL,
      "notes"         TEXT,
      "paidAt"        TIMESTAMPTZ,
      "archivedAt"    TIMESTAMPTZ,
      "createdAt"     TIMESTAMPTZ NOT NULL DEFAULT NOW(),
      "updatedAt"     TIMESTAMPTZ NOT NULL DEFAULT NOW(),
      CONSTRAINT "SysAdminInvoice_pkey" PRIMARY KEY ("id"),
      CONSTRAINT "SysAdminInvoice_invoiceNumber_key" UNIQUE ("invoiceNumber"),
      CONSTRAINT "SysAdminInvoice_tenantId_fkey"
        FOREIGN KEY ("tenantId") REFERENCES "Tenant"("id") ON DELETE RESTRICT ON UPDATE CASCADE
    );

    CREATE INDEX "SysAdminInvoice_tenantId_idx" ON "SysAdminInvoice"("tenantId");
    CREATE INDEX "SysAdminInvoice_status_idx"   ON "SysAdminInvoice"("status");
    CREATE INDEX "SysAdminInvoice_dueDate_idx"  ON "SysAdminInvoice"("dueDate");
    CREATE INDEX "SysAdminInvoice_archivedAt_idx" ON "SysAdminInvoice"("archivedAt");

    -- Create SysAdminInvoiceItem table
    CREATE TABLE "SysAdminInvoiceItem" (
      "id"          UUID NOT NULL DEFAULT gen_random_uuid(),
      "invoiceId"   UUID NOT NULL,
      "description" TEXT NOT NULL,
      "quantity"    DECIMAL(10,2) NOT NULL,
      "unitPrice"   DECIMAL(10,2) NOT NULL,
      "amount"      DECIMAL(12,2) NOT NULL,
      CONSTRAINT "SysAdminInvoiceItem_pkey" PRIMARY KEY ("id"),
      CONSTRAINT "SysAdminInvoiceItem_invoiceId_fkey"
        FOREIGN KEY ("invoiceId") REFERENCES "SysAdminInvoice"("id") ON DELETE CASCADE ON UPDATE CASCADE
    );

    CREATE INDEX "SysAdminInvoiceItem_invoiceId_idx" ON "SysAdminInvoiceItem"("invoiceId");

    -- RLS: tenant users must never see sysadmin invoices
    -- Admin portal uses base prisma client (no RLS session variable set),
    -- so these tables are effectively admin-only.
    ALTER TABLE "SysAdminInvoice"     ENABLE ROW LEVEL SECURITY;
    ALTER TABLE "SysAdminInvoiceItem" ENABLE ROW LEVEL SECURITY;

    CREATE POLICY "sysadmin_invoices_deny_tenant_users"
      ON "SysAdminInvoice" FOR ALL
      USING (current_setting('app.current_tenant_id', TRUE) IS NULL
          OR current_setting('app.current_tenant_id', TRUE) = '');

    CREATE POLICY "sysadmin_invoice_items_deny_tenant_users"
      ON "SysAdminInvoiceItem" FOR ALL
      USING (current_setting('app.current_tenant_id', TRUE) IS NULL
          OR current_setting('app.current_tenant_id', TRUE) = '');
    ```

  <action>
    Create `src/app/(admin)/actions/sysadmin-invoices.ts` with `'use server'` at top.

    **Imports:** requireAuth + isSystemAdmin from @/lib/auth/server, prisma from @/lib/db/prisma, revalidatePath from next/cache, Decimal from decimal.js, z from zod.

    **requireAdminAccess helper** — same pattern as tenants.ts: call requireAuth(), call isSystemAdmin(), throw if not admin.

    **generateInvoiceNumber()** — exported async function:
    - Query `prisma.sysAdminInvoice.findFirst({ orderBy: { invoiceNumber: 'desc' }, select: { invoiceNumber: true } })`
    - Parse last number: match /SINV-(\d+)/ → increment by 1, default to 1 if no records
    - Return `SINV-${String(next).padStart(4, '0')}` (e.g. SINV-0001, SINV-0042)

    **createSysAdminInvoice(data)** — accepts typed object:
    ```typescript
    {
      tenantId: string;
      dueDate: string;       // ISO date string
      notes?: string;
      items: Array<{ description: string; quantity: number; unitPrice: number }>;
    }
    ```
    - requireAdminAccess()
    - Validate with Zod: tenantId uuid, dueDate valid date, items array min 1 item, each item: description non-empty, quantity > 0, unitPrice >= 0
    - Call generateInvoiceNumber()
    - Compute subtotal and total using Decimal.js: sum of (quantity * unitPrice) per item; store as Prisma Decimal-compatible strings
    - Create invoice with `prisma.sysAdminInvoice.create` including nested `items: { create: [...] }` with pre-computed amount per item
    - issueDate = new Date() (now), status = DRAFT
    - revalidatePath('/admin/billing')
    - Return { success: true, invoice }

    **getSysAdminInvoices(filters?)** — accepts optional `{ tenantId?: string; status?: string }`:
    - requireAdminAccess()
    - Query `prisma.sysAdminInvoice.findMany` with:
      - where: { archivedAt: null, ...(tenantId filter), ...(status filter) }
      - include: { tenant: { select: { id: true, name: true } } }
      - orderBy: { createdAt: 'desc' }
    - Return array

    **getSysAdminInvoiceById(id)** — returns full invoice with items and tenant owner email:
    - requireAdminAccess()
    - Query `prisma.sysAdminInvoice.findUnique` with include: items + tenant (name)
    - Separately query `prisma.user.findFirst({ where: { tenantId: invoice.tenantId, role: 'OWNER', isActive: true }, select: { email: true, firstName: true, lastName: true } })`
    - Return { ...invoice, ownerUser }

    **updateSysAdminInvoice(id, data)** — only allowed when status === DRAFT:
    - requireAdminAccess()
    - Load invoice, throw if not DRAFT ("Cannot edit a sent or paid invoice")
    - Same Zod validation as create (items, dueDate, notes)
    - Delete existing items, recompute totals, update invoice + create new items in a prisma.$transaction
    - revalidatePath('/admin/billing')
    - Return { success: true }

    **markInvoicePaid(id)** — transition SENT or OVERDUE → PAID:
    - requireAdminAccess()
    - Load invoice, throw if already PAID or VOID
    - Update: status = PAID, paidAt = new Date()
    - revalidatePath('/admin/billing')
    - Return { success: true }

    **voidInvoice(id)** — transition DRAFT or SENT → VOID:
    - requireAdminAccess()
    - Load invoice, throw if PAID or already VOID ("Cannot void a paid invoice")
    - Update: status = VOID
    - revalidatePath('/admin/billing')
    - Return { success: true }

    **archiveInvoice(id)** — soft delete, only DRAFT:
    - requireAdminAccess()
    - Load invoice, throw if not DRAFT
    - Update: archivedAt = new Date()
    - revalidatePath('/admin/billing')
    - Return { success: true }

    **markOverdueInvoices()** — batch transition SENT → OVERDUE where dueDate < now:
    - requireAdminAccess()  (also called from cron — cron handles its own auth)
    - `prisma.sysAdminInvoice.updateMany({ where: { status: 'SENT', dueDate: { lt: new Date() }, archivedAt: null }, data: { status: 'OVERDUE' } })`
    - Return { count: result.count }

    All error returns follow the pattern: `{ success: false, error: string }`.
    All actions use base `prisma` client (NOT getTenantPrisma).
