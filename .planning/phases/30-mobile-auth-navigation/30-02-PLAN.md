# Phase 30 — Plan 02: Navigation Shell + Shared UI Primitives

## Goal
Build the bottom tab navigators for driver and owner portals with placeholder screens, and create the shared UI component library used throughout the entire app.

## Prerequisites
- Plan 30-01 complete (auth works, user.role available)

## Tasks

### 1. Driver tab navigator
File: apps/mobile/app/(driver)/_layout.tsx
```typescript
import { Tabs } from 'expo-router'
import { House, Truck, Clock, MessageSquare, FileText } from 'lucide-react-native'

export default function DriverLayout() {
  return (
    <Tabs
      screenOptions={{
        headerShown: false,
        tabBarShowLabel: false,
        tabBarStyle: {
          backgroundColor: '#1e293b',
          borderTopColor: '#334155',
          height: 64,
          paddingBottom: 8,
        },
        tabBarActiveTintColor: '#0ea5e9',
        tabBarInactiveTintColor: '#64748b',
      }}
    >
      <Tabs.Screen name="index" options={{ tabBarIcon: ({ color }) => <House color={color} size={24} /> }} />
      <Tabs.Screen name="loads" options={{ tabBarIcon: ({ color }) => <Truck color={color} size={24} /> }} />
      <Tabs.Screen name="hos" options={{ tabBarIcon: ({ color }) => <Clock color={color} size={24} /> }} />
      <Tabs.Screen name="messages" options={{ tabBarIcon: ({ color, focused }) => (
        // Badge overlay for unread count — implemented in Phase 34
        <MessageSquare color={color} size={24} />
      )}} />
      <Tabs.Screen name="documents" options={{ tabBarIcon: ({ color }) => <FileText color={color} size={24} /> }} />
    </Tabs>
  )
}
```

Driver placeholder screens (one file each, replaced in later phases):
- app/(driver)/index.tsx → "Driver Dashboard" placeholder
- app/(driver)/loads.tsx → "Loads" placeholder
- app/(driver)/hos.tsx → "HOS" placeholder
- app/(driver)/messages.tsx → "Messages" placeholder
- app/(driver)/documents.tsx → "Documents" placeholder

### 3. Shared UI primitives
Directory: apps/mobile/components/ui/

#### Button.tsx
```typescript
interface ButtonProps {
  title: string
  onPress: () => void
  variant?: 'primary' | 'secondary' | 'destructive' | 'ghost'
  size?: 'sm' | 'md' | 'lg'
  isLoading?: boolean
  disabled?: boolean
  icon?: React.ReactNode
}
```

Minimum height 48px (h-12). Loading state shows ActivityIndicator replacing title. All variants styled with NativeWind.

#### Card.tsx
```typescript
interface CardProps {
  children: React.ReactNode
  className?: string
  onPress?: () => void  // makes it a Pressable
}
```

Background: `bg-slate-800`, border: `border border-slate-700`, rounded: `rounded-xl`, padding: `p-4`.

#### Badge.tsx
```typescript
interface BadgeProps {
  label: string
  variant: 'success' | 'warning' | 'danger' | 'info' | 'muted'
}
```

Maps to status colors (ACTIVE=success, EXPIRING=warning, EXPIRED=danger, etc.)

#### Input.tsx
```typescript
interface InputProps {
  label?: string

  value: string
  onChangeText: (text: string) => void
  error?: string
  secureTextEntry?: boolean
  keyboardType?: KeyboardTypeOptions
  autoFocus?: boolean
  returnKeyType?: ReturnKeyTypeOptions
  onSubmitEditing?: () => void
  blurOnSubmit?: boolean
}
```

Dark themed: `bg-slate-800 border-slate-600 text-white`. Error state: `border-red-500` + error text below.
