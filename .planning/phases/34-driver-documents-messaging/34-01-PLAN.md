# Phase 34 — Plan 01: Driver Documents Screen

## Goal
Build the documents list screen with expiry status, document detail bottom sheet, and document upload flow with file picker and S3 upload.

## Prerequisites
- Phase 30 complete
- expo-document-picker, expo-file-system installed (Phase 29)
- S3 multipart upload utility from Phase 32 (lib/upload.ts)

### 7. Build document upload bottom sheet
File: apps/mobile/components/driver/DocumentUploadSheet.tsx

Fields:
1. Document Type (custom select → bottom list)
2. Document Name (TextInput, auto-filled based on type)
3. Expiry Date (DateTimePicker from @react-native-community/datetimepicker or expo date picker)
4. File Selection: "Pick File" button (expo-document-picker) or "Take Photo" button (expo-image-picker)
5. Selected file display (name + size)
6. Upload Progress bar (0-100%)
7. Submit button

Flow:
1. User fills fields + selects file
2. Tap Submit → validate fields
3. Upload file to S3 via lib/upload.ts (shows progress)
4. On S3 complete → POST /api/mobile/driver/documents with s3Key
5. Success → close sheet + refresh list + success toast
6. Error → error toast, keep sheet open

Install: `npm install @react-native-community/datetimepicker` (or use expo date pickers)
