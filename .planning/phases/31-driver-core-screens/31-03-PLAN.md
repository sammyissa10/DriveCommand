**apps/mobile/components/driver/StatusUpdateButton.tsx:**
Props: `{ load: LoadDetail, onStatusUpdated: () => void }`
Logic:
- Derive next action from current status:
  - PENDING -> { label: 'Accept Load', nextStatus: 'ACCEPTED' }
  - ACCEPTED -> { label: 'Start Route', nextStatus: 'EN_ROUTE' }
  - EN_ROUTE -> { label: 'Mark Delivered', nextStatus: 'DELIVERED' }
  - DELIVERED/INVOICED/CANCELLED -> return null (render nothing)
- Large button at bottom (full-width, brand color, text-lg font-semibold). This should feel "weighty" per user decision — larger padding, bold text.
- On press: open React Native Modal (NOT a third-party bottom sheet — use built-in Modal with `animationType="slide"` and `transparent={true}`, positioned at bottom with a white/dark card)
- Modal content:
  - Title: "Confirm: [Action Label]"
  - Body: "Load #[number] — [Origin] to [Destination]"
  - Two buttons: "Cancel" (ghost/outline style) and "Confirm" (primary, shows loading spinner when pressed)
- On confirm:
  1. Set loading state
  2. Call `driverApi.updateLoadStatus(token, load.id, nextStatus)`
  3. On success: trigger haptic feedback (`expo-haptics` Haptics.notificationAsync(Success)`), close modal, invalidate TanStack Query cache for driver-loads and driver-dashboard, call onStatusUpdated
  4. On error: close modal, show toast via `Toast.show({ type: 'error', text1: 'Update Failed', text2: error.message })`, re-enable button

Install expo-haptics if not already present: `npx expo install expo-haptics`
