### 3. Build status update flow
File: apps/mobile/components/driver/StatusUpdateButton.tsx

```typescript
interface StatusUpdateButtonProps {
  load: Load
  onStatusUpdated: (updatedLoad: Load) => void
}

// Derive button label from current status:
const getNextAction = (status: LoadStatus): { label: string; nextStatus: LoadStatus } | null => ({
  PENDING: { label: 'Accept Load', nextStatus: 'ACCEPTED' },
  ACCEPTED: { label: 'Start Route', nextStatus: 'EN_ROUTE' },
  EN_ROUTE: { label: 'Mark Delivered', nextStatus: 'DELIVERED' },
  DELIVERED: null, // No action
  INVOICED: null,
  CANCELLED: null,
}[status] ?? null)
```

Confirmation bottom sheet:
- Title: "Confirm: [Action Label]"
- Body: "Load #XXXX — [Origin] to [Destination]"
- Two buttons: "Cancel" (ghost) + "Confirm" (primary, loading state on press)
- On confirm: call driverApi.updateLoadStatus → haptic success → close sheet → invalidate query → navigate back to loads list

Error handling:
- API error → close sheet → show toast (Sonner equivalent: `react-native-toast-message` or expo-toast)
- Keep button enabled for retry
