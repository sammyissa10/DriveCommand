# Phase 29 — Plan 02: Expo App Scaffold + NativeWind + EAS Config

## Goal
Create the apps/mobile/ Expo project with Expo Router v4, NativeWind v4, and EAS configuration. A working blank app boots on a physical device via Expo Go or a development build.

## Prerequisites
- Plan 29-01 complete (monorepo structure exists)
- EAS account created at expo.dev (user action required)
- Apple Developer Program enrolled (user action required)
- Google Play Console enrolled (user action required)

## Tasks

### 1. Create Expo app with Expo Router template
```bash
cd apps
npx create-expo-app@latest mobile --template tabs
cd mobile
```

This generates the Expo Router file-based structure. We'll clean it up in subsequent steps.

### 3. Install core dependencies
```bash
cd apps/mobile
npx expo install expo-router expo-constants expo-linking expo-status-bar react-native-safe-area-context react-native-screens
npx expo install expo-location expo-camera expo-notifications expo-document-picker expo-file-system expo-image-picker expo-local-authentication
npx expo install react-native-mmkv
npx expo install @react-native-community/netinfo
npx expo install expo-haptics expo-image
npx expo install react-native-maps react-native-map-clustering
```

### 4. Install NativeWind v4
```bash
cd apps/mobile
npm install nativewind tailwindcss
```

Create apps/mobile/tailwind.config.js:
```js
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: ["./app/**/*.{js,jsx,ts,tsx}", "./components/**/*.{js,jsx,ts,tsx}"],
  presets: [require("nativewind/preset")],
  theme: {
    extend: {
      colors: {
        // Match web app design tokens
        brand: {
          50: "#f0f9ff",
          500: "#0ea5e9",
          600: "#0284c7",
          900: "#0c4a6e",
        },
        surface: {
          DEFAULT: "#0f172a",
          card: "#1e293b",
          border: "#334155",
        }
      },
      fontFamily: {
        sans: ["System"],
        heading: ["Poppins-SemiBold"],
      }
    }
  },
  plugins: [],
}
```

Create apps/mobile/metro.config.js:
```js
const { getDefaultConfig } = require("expo/metro-config");
const { withNativeWind } = require("nativewind/metro");

const config = getDefaultConfig(__dirname);
module.exports = withNativeWind(config, { input: "./global.css" });
```

Create apps/mobile/global.css:
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

### 6. Clean up template and create minimal app structure
Replace template content with clean structure:

```
apps/mobile/app/
├── _layout.tsx        ← root layout (fonts, safe area, auth guard)
├── index.tsx          ← redirects to /login or /(driver) or /(owner)
├── login.tsx          ← login screen (placeholder for Phase 30)
├── (driver)/
│   └── _layout.tsx    ← placeholder tab navigator
└── (owner)/
    └── _layout.tsx    ← placeholder tab navigator
```

Root `_layout.tsx`:
```tsx
import { Stack } from 'expo-router'
import { SafeAreaProvider } from 'react-native-safe-area-context'
import '../global.css'

export default function RootLayout() {
  return (
    <SafeAreaProvider>
      <Stack screenOptions={{ headerShown: false }} />
    </SafeAreaProvider>
  )
}
```

### 7. Create .eas.json
```json
{
  "cli": { "version": ">= 12.0.0" },
  "build": {
    "development": {
      "developmentClient": true,

      "env": { "EXPO_PUBLIC_API_URL": "http://localhost:3000" }
    },
    "preview": {
      "distribution": "internal",
      "env": { "EXPO_PUBLIC_API_URL": "https://your-production-url.vercel.app" }
    },
    "production": {
      "autoIncrement": true,
      "env": { "EXPO_PUBLIC_API_URL": "https://your-production-url.vercel.app" }
    }
  },
  "submit": {
    "production": {
      "ios": {
        "appleId": "your-apple-id@email.com",
        "ascAppId": "your-app-store-connect-app-id",
        "appleTeamId": "your-team-id"
      },
      "android": {
        "serviceAccountKeyPath": "./google-play-key.json",
        "track": "production"
      }
    }
  }
}
```

### 8. Create apps/mobile/package.json scripts
```json
{
  "scripts": {
    "start": "expo start",
    "android": "expo run:android",
    "ios": "expo run:ios",
    "build:dev": "eas build --profile development --platform all",
    "build:preview": "eas build --profile preview --platform all",
    "build:prod": "eas build --profile production --platform all"
  }
}
```

### 9. Load Poppins font
```bash
npx expo install expo-font @expo-google-fonts/poppins
```

In root _layout.tsx:
```tsx
import { useFonts, Poppins_600SemiBold } from '@expo-google-fonts/poppins'
import * as SplashScreen from 'expo-splash-screen'
```

### 10. Add placeholder assets
Create apps/mobile/assets/images/:
- icon.png (1024×1024 — DriveCommand logo, solid background, no transparency)
- splash-icon.png (200×200 — logo centered)
- adaptive-icon.png (1024×1024 — Android adaptive icon foreground)

Use existing DriveCommand logo assets from public/.
