# Phase 29 — Plan 01: Turborepo Setup + Web App Migration

## Goal
Convert the existing single-repo into a Turborepo monorepo. Move the web app into apps/web/. Verify the web app builds identically after the move.

## Context
- Existing repo root IS the Next.js app (package.json at root has next, react, etc.)
- After this plan: root package.json is the workspace root, Next.js lives in apps/web/
- Nothing inside apps/web/ changes — same files, same imports, same env vars
- Vercel must be reconfigured to point to apps/web/ as root

## Tasks

### 1. Create workspace directory structure
```
mkdir -p apps/web
mkdir -p apps/mobile
mkdir -p packages/types/src
mkdir -p packages/validation/src
mkdir -p packages/api-client/src
```

### 2. Move existing Next.js files to apps/web/
Move all current repo files EXCEPT: `.git/`, `.gitignore` (root), `.planning/`, `CLAUDE.md`, `turbo.json` (doesn't exist yet)

Files to move into apps/web/:
- src/
- public/
- prisma/
- scripts/
- docs/ (if exists)
- e2e/
- package.json → apps/web/package.json
- tsconfig.json → apps/web/tsconfig.json
- next.config.js (or .mjs, .ts)
- tailwind.config.js (or .ts)
- postcss.config.js
- .env (stays in root AND apps/web/ — keep both for Vercel)
- .env.example
- playwright.config.ts
- vitest.config.ts (if exists)

### 3. Create root package.json (workspace root)
```json
{
  "name": "drivecommand-monorepo",
  "private": true,
  "workspaces": ["apps/*", "packages/*"],
  "scripts": {
    "dev": "turbo run dev",
    "build": "turbo run build",
    "lint": "turbo run lint",
    "test": "turbo run test"
  },
  "devDependencies": {
    "turbo": "^2.0.0",
    "typescript": "^5"
  }
}
```

### 4. Create turbo.json
```json
{
  "$schema": "https://turbo.build/schema.json",
  "tasks": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": [".next/**", "!.next/cache/**", "dist/**"]
    },
    "dev": {
      "cache": false,
      "persistent": true
    },
    "lint": {
      "outputs": []
    },
    "test": {
      "outputs": ["coverage/**"]
    }
  }
}
```

### 5. Create stub package.json files for shared packages
Each package needs: name, version, main, types, scripts.build.

packages/types/package.json:
```json
{
  "name": "@drivecommand/types",
  "version": "0.1.0",
  "private": true,
  "main": "./dist/index.js",
  "types": "./dist/index.d.ts",
  "scripts": { "build": "tsc", "dev": "tsc --watch" }
}
```

Same pattern for packages/validation and packages/api-client.

### 6. Create root tsconfig.json (base config)
```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "skipLibCheck": true
  }
}
```

### 7. Update apps/web/package.json
- Change name to `"@drivecommand/web"`
- Add workspace deps: `"@drivecommand/types": "*"`, `"@drivecommand/validation": "*"`

### 8. Install dependencies
```bash
npm install  # from repo root — installs all workspaces
```

### 9. Verify web app still builds
```bash
cd apps/web && npm run build
# OR from root:
turbo run build --filter=@drivecommand/web
```

Fix any import path issues that arise from the directory move.

### 10. Update .gitignore at repo root
Add: `apps/web/.next/`, `apps/web/node_modules/`, `packages/*/dist/`, `packages/*/node_modules/`

## Verification
- [ ] `turbo run build --filter=@drivecommand/web` completes with no errors
- [ ] `cd apps/web && npm run dev` starts the Next.js dev server
- [ ] All existing pages load correctly in browser
- [ ] No TypeScript errors in apps/web/
- [ ] Monorepo directory structure matches plan

## Notes
- Do NOT change any file inside apps/web/src/ — only the directory it lives in changes
- The .env file should exist at apps/web/.env (Vercel reads it from the app root)
- After this plan, Vercel project settings need Root Directory updated to `apps/web` — remind user
