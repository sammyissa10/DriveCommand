<task type="auto">
  <name>Task 1: Create GET /api/mobile/driver/hos endpoint</name>
  <files>apps/web/src/app/api/mobile/driver/hos/route.ts</files>
  <action>
Create `apps/web/src/app/api/mobile/driver/hos/route.ts` with a GET handler.

Follow the exact same auth + Prisma transaction pattern as `apps/web/src/app/api/mobile/driver/loads/route.ts`:
- Import validateMobileToken, unauthorizedResponse from mobile-auth
- Import prisma, TX_OPTIONS from @/lib/db/prisma
- Call validateMobileToken, return 401 if null, check driverId exists (403 if not driver)

**GET handler logic:**

1. Determine "today" boundaries: start of day and end of day in UTC (use `new Date()` with setUTCHours).

2. Query all DriverHOSEntry records for this driver where `startTime >= startOfDay` OR `endTime IS NULL` (the currently open entry might have started yesterday). Order by startTime ASC.

3. Determine current status: find the entry where `endTime IS NULL`. If none exists, default to `OFF_DUTY` with `currentStatusSince` = start of day.

4. Calculate clocks:
   - `drivingMinutesToday`: sum of all DRIVING entries' durations today (for open entry, use now as endTime)
   - `onDutyMinutesToday`: sum of all DRIVING + ON_DUTY entries' durations today
   - `hoursUntil14Limit`: Math.max(0, 14 - (onDutyMinutesToday / 60)). The 14-hour window starts from the FIRST non-OFF_DUTY/non-SLEEPER_BERTH entry of the day.
   - `hoursUntil11DriveLimit`: Math.max(0, 11 - (drivingMinutesToday / 60))
   - `timeInCurrentStatus`: seconds since currentStatusSince

5. Return JSON matching the HOSData type from packages/types:
```json
{
  "currentStatus": "DRIVING",
  "currentStatusSince": "2026-03-22T08:00:00Z",
  "timeInCurrentStatus": 3600,
  "todayEntries": [...],
  "drivingMinutesToday": 180,
  "onDutyMinutesToday": 360,
  "hoursUntil14Limit": 8.0,
  "hoursUntil11DriveLimit": 8.0
}
```

Wrap DB queries in `prisma.$transaction` with `TX_OPTIONS` and the RLS bypass pattern used in loads/route.ts.

  <name>Task 2: Create POST /api/mobile/driver/hos endpoint</name>
  <files>apps/web/src/app/api/mobile/driver/hos/route.ts</files>
  <action>
Add a POST handler to the same route.ts file.

**POST handler logic:**

1. Auth: same validateMobileToken pattern
2. Parse body: `{ status: HOSDutyStatus, notes?: string }`
3. Validate status is one of: OFF_DUTY, SLEEPER_BERTH, DRIVING, ON_DUTY. Return 400 if invalid.
4. Inside a Prisma transaction (with RLS bypass):
   a. Find the current open entry (endTime IS NULL) for this driver
   b. If the open entry has the SAME status as requested, return 400: `{ error: "Already in this status" }`
   c. If an open entry exists, update it: set endTime = now()
   d. Create a new DriverHOSEntry: `{ tenantId, driverId, status, startTime: now(), notes }`
5. Return 201 with `{ entry: newEntry }`

Use the same Prisma transaction + RLS bypass pattern as the loads endpoint.

  apiRequest<{ entry: HOSEntry }>('/api/mobile/driver/hos', {

  }),
