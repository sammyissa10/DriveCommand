**HOSDayBar.tsx:**

```typescript
interface HOSDayBarProps {
  entries: HOSEntry[]
  currentStatus: HOSStatus
}
```

- Use View with flexDirection: 'row' to render segments (per Claude's discretion — View segments approach)
- Bar height: 32px, rounded-lg, bg-slate-700 (empty background)
- Each entry becomes a colored segment proportional to its duration within the 24-hour day
- Duration calculation: for each entry, compute (endTime - startTime) / totalDayMs as flex ratio. For the currently open entry (no endTime), use `new Date()` as endTime.
- Segment colors match status colors: OFF_DUTY=#475569 (slate-600), SLEEPER_BERTH=#7c3aed (purple-600), DRIVING=#16a34a (green-600), ON_DUTY=#0284c7 (sky-600)
- Current time marker: thin vertical View (width 2, full bar height, bg-red-500) positioned at the proportional current-time offset using absolute positioning
- Hour labels below: "12a", "6a", "12p", "6p", "12a" — 5 Text elements evenly spaced in a row below the bar, text-xs text-slate-500

**HOSClock.tsx:**

```typescript
interface HOSClockProps {
  label: string       // "14-Hour Limit" or "11-Hour Drive"
  hoursRemaining: number
  isWarning?: boolean  // true when < 2 hours
}
```

- Display label above the clock (text-sm text-slate-400)
- Large HH:MM:SS display using a useEffect + setInterval that decrements every 1 second from the initial `hoursRemaining` value
- Convert hours (decimal) to total seconds internally: `totalSeconds = Math.round(hoursRemaining * 3600)`, decrement by 1 each tick
- Format display: `HH = Math.floor(totalSeconds / 3600)`, `MM = Math.floor((totalSeconds % 3600) / 60)`, `SS = totalSeconds % 60` — pad each with 2 digits
- Normal state: text-white text-3xl font-mono font-bold
- Warning state (isWarning or computed hoursRemaining < 2): text-red-500 text-3xl font-mono font-bold
- Container: bg-slate-800 rounded-xl p-4, flex-1 (so two clocks sit side by side)

   - onPress opens the confirmation modal (see below)
