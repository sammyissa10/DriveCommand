### 7. Build main HOS screen
File: apps/mobile/app/(driver)/hos.tsx

Layout (ScrollView):
- ScreenWrapper
- Section: "Current Status" — large badge showing current status + "for X hours Y min"
- Section: 2×2 grid of HOSStatusCard components
- Section: HOSDayBar (daily log visualization)
- Section: two HOSClock components side by side (14-hr and 11-hr)

Data: useQuery calling driverApi.getHOS(token).
Polling: refetchInterval: 60_000 (refresh every minute for clock accuracy).

### 8. Status change confirmation
When driver taps a different status card:
- Open BottomSheet with:
  - "Change Status to: [New Status]"
  - Optional notes TextInput
  - "Confirm" + "Cancel" buttons
- On confirm: call driverApi.updateHOSStatus → haptic → close sheet → invalidate HOS query
- On same status tap: show toast "Already [Status]"
