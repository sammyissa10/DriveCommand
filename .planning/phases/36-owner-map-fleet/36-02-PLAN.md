### 2. Build fleet messaging screen
File: apps/mobile/app/(owner)/fleet.tsx

Two-panel view with toggle at top ("Compose" | "History"):

Compose panel:
- Recipient selector: "All Drivers" option + list of individual active drivers
- Selected recipient chip (name with ✕ to clear)
- Message textarea (multiline, 4 lines, maxLength 500, character counter)
- Send button (full width, loading state)
- On success: show "Message sent!" toast, clear form

History panel (FlashList):
- Each row: recipient name (or "All Drivers"), message preview, timestamp
- Tap a row → MessageHistorySheet (shows full message text + recipient + time sent)
- Pull-to-refresh
