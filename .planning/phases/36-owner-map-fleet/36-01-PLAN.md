Create GET /api/mobile/owner/map/vehicles endpoint:
- Auth: Bearer token → tenantId, require OWNER role
- Query GpsLocation records for trucks belonging to the tenant
- Join with Truck, Driver (assigned), and active Load
- Compute status for each vehicle:
  - OFFLINE: lastPingAt > 10 minutes ago
  - MOVING: speed > 8 km/h (5 mph) and within 10 min
  - IDLE: recent ping but speed ≈ 0
- Return JSON: { vehicles: MapVehicle[] }
- MapVehicle shape: { truckId, truckName, driverName, driverId, latitude, longitude, speed, heading, lastPingAt, status, loadNumber }

In packages/api-client/src/owner.ts:
- Add MapVehicle type interface matching the response shape above (include status as 'MOVING' | 'IDLE' | 'OFFLINE' union)
- Add getMapVehicles method to ownerApi: `getMapVehicles: (token: string) => apiRequest<{ vehicles: MapVehicle[] }>('/api/mobile/owner/map/vehicles', { token })`
- Export MapVehicle type
