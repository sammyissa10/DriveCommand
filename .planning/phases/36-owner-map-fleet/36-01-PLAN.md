# Phase 36 — Plan 01: Live Map Screen

## Goal
Build the live map screen with react-native-maps, vehicle markers with status colors, and vehicle detail bottom sheet.

## Prerequisites
- Phase 35 complete (owner screens pattern established)
- react-native-maps installed (Phase 29)
- Existing /api/gps/locations endpoint returns vehicle positions
