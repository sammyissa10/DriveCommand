## What Was Built

### Task 1: Consolidation

**apps/web/src/lib/auth/supabase.ts** — New unified auth module. Merged content from three files into one with clear section headers:

- Session section: `SessionData` interface + `getSession()` (react cache)
- Role & Auth checks: `getRole()`, `requireAuth()`, `requireRole()`, `isSystemAdmin()`, `getCurrentUser()`
- Permission checks: `requirePermission()`

All function signatures are byte-for-byte identical to the originals. No behavioral changes.

**Import path migration** — Three sed passes updated all files importing from `@/lib/auth/session`, `@/lib/auth/server`, or `@/lib/auth/require-permission` to `@/lib/auth/supabase`. Since 19 files previously imported from two different old modules (e.g., `server` + `session`), those produced duplicate import lines that were merged into single combined imports via Node.js script.

Files updated: 72 source files + 2 test files = 74 total. Old files deleted.
