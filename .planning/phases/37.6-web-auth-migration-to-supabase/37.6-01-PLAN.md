<objective>
Fix the primary security gap: move all security-critical claims (role, tenantId, isSystemAdmin, permissions) from user_metadata (user-editable) to app_metadata (admin-only, tamper-proof) in both the user creation path and all metadata readers.

Purpose: user_metadata is user-writable via supabase.auth.updateUser(). Any authenticated user could currently overwrite their role, tenantId, or isSystemAdmin. Moving these to app_metadata (only writable via service role) closes this privilege escalation vector.

Output: All 6 files updated atomically so writes and reads are consistent.
</objective>
