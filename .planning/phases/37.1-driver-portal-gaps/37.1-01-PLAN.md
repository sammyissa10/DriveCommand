  <action>
Create two new mobile API endpoints and add three methods to the driver api-client.

**GET /api/mobile/driver/route** (`apps/web/src/app/api/mobile/driver/route/route.ts`):
- Follow the exact pattern from `/api/mobile/driver/loads/route.ts` for auth + rate limiting
- Use `validateMobileToken(req)` + `applyRateLimit(mobileLimiter, auth.userId)`
- Query: Find the driver's currently assigned route where status is NOT 'COMPLETED'. Use `prisma.$queryRawUnsafe` with `bypass_rls` or the existing RLS-aware pattern from other driver endpoints.
- Prisma include: `loads` (select: id, loadNumber, origin, destination, status), `truck` (select: make, model, year, vin, licensePlate)
- Select on route: id, name, origin, destination, status, scheduledDate, completedAt
- If no active route found, return `{ route: null }` with 200 (not 404)
- Return `{ route: {...} }` with 200

**GET/POST /api/mobile/driver/messages/route-thread** (`apps/web/src/app/api/mobile/driver/messages/route-thread/route.ts`):
- Model on the existing `/api/mobile/driver/messages/route.ts` endpoint pattern
- GET: Accept `?routeId=` query param. Verify route belongs to this driver (query route by id + driverId + tenantId). Return messages where `routeId` matches, ordered by `createdAt asc`. Include sender info.
- POST: Accept `{ routeId, body }`. Verify route ownership. Create FleetMessage with `routeId` set (NOT `loadId`), `senderId` = auth.userId, `senderRole` = 'DRIVER'. Return created message.
- Both handlers: `validateMobileToken` + `applyRateLimit`
- IMPORTANT: This endpoint is SEPARATE from the general messages endpoint. Do NOT modify the existing `/api/mobile/driver/messages/route.ts`.

**api-client updates** (`packages/api-client/src/driver.ts`):
- Add `getMyRoute()`: GET `/api/mobile/driver/route` -> returns `{ route: RouteData | null }`
- Add `getRouteMessages(routeId: string)`: GET `/api/mobile/driver/messages/route-thread?routeId=${routeId}` -> returns message array
- Add `sendRouteMessage(routeId: string, body: string)`: POST `/api/mobile/driver/messages/route-thread` with `{ routeId, body }` -> returns created message
- Define a `DriverRoute` type inline or use the existing Route type if compatible
  </action>
