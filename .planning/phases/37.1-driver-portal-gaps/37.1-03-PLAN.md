  - `status: 'OPEN'`

**SupportTicketFAB** (`apps/mobile/components/shared/SupportTicketFAB.tsx`):
- Self-contained component: FAB button + BottomSheet + form + submission logic
- Import `usePathname` from `expo-router` for `fromPage`
- Import `BottomSheet` from `components/ui/BottomSheet`
- Import `Toast` from `react-native-toast-message`
- Import the `createSupportTicket` api-client method

**FAB button:**
- `position: 'absolute'`, `bottom: 88` (above 72px tab bar + 16px room), `right: 20`
- Size: 48x48, borderRadius 24, backgroundColor '#0ea5e9' (sky-500)
- LifeBuoy icon from lucide-react-native, color white, size 22
- Shadow: elevation 4 (Android), shadowColor/offset/opacity/radius (iOS)
- On press: open bottom sheet (`setVisible(true)`)

**Bottom sheet form** (inside BottomSheet, snapPoint "80%"):
- Wrap form content in `ScrollView` to handle keyboard on Android (per research pitfall 1)
- **Category picker**: row of pill buttons (Billing, Bug Report, Feature Request, General). Active pill: bg-sky-600 text-white. Inactive: bg-slate-700 text-slate-300. Default: General.
- **Priority picker**: row of pill buttons (Low, Normal, High, Urgent). Default: Normal. Same active/inactive styling.
- **Title input**: TextInput with placeholder "Brief summary", bg-slate-800, border-slate-600, rounded-lg, p-3, text-white. Show validation error below if < 3 chars on blur.
- **Description input**: TextInput multiline, numberOfLines 4, placeholder "Describe your issue in detail...", same styling. Max 2000 chars. Show char count (e.g. "42/2000"). Validation: min 10 chars shown on blur.
- **Submit button**: full-width, bg-sky-600, rounded-lg, py-3, "Submit Ticket" text. Disabled state (opacity-50) when submitting or form invalid.

**Submission logic:**
- Use `useMutation` calling `createSupportTicket({ category, priority, title, description, fromPage: pathname })`
- `platform` is NOT sent from client — the API hardcodes 'MOBILE'
- On success: `Toast.show({ type: 'success', text1: 'Ticket #${ticketNumber} submitted!', text2: "We'll be in touch soon." })`, close bottom sheet, reset all form fields to defaults
- On error: `Toast.show({ type: 'error', text1: 'Failed to submit ticket', text2: 'Please try again.' })`, keep sheet open

**Wire into layouts:**
- In `apps/mobile/app/(driver)/_layout.tsx`: import `SupportTicketFAB`, add `<SupportTicketFAB />` inside the Fragment, after the `<Tabs>` component (same level as NotificationPermissionModal)
- In `apps/mobile/app/(owner)/_layout.tsx`: same pattern — import and add `<SupportTicketFAB />` inside the Fragment after Tabs
- Do NOT add explicit zIndex to the FAB — let RN Modal system handle layering (per research pitfall 2)
