## Decisions Made
- Platform hardcoded as MOBILE in API, not sent from client — prevents spoofing
- `createSupportTicket` re-exported from index.ts as a wrapper function (not direct re-export of `driverApi.createSupportTicket`) to avoid `driverApi` not being in scope in module body — used a private `_driverApi` import alias
- api-client `dist/` rebuilt via `tsc` after source changes since mobile TypeScript resolves to `dist/index.d.ts` via the symlinked workspace package

## Deviations from Plan

None — plan executed exactly as written.

## Issues Encountered
- api-client `dist/` was stale after adding `createSupportTicket` — TypeScript error `Module has no exported member 'createSupportTicket'` in mobile. Fixed by running `tsc` in packages/api-client to regenerate dist (dist is gitignored, normal for workspace packages).
- `useMutation` inferred `data` as `unknown` in `onSuccess` callback — fixed by explicitly typing the mutation generics `useMutation<{ ticketNumber: string }, Error, void>`.
