**Step B: Add SampleDataBanner to the 5 pages**

For each page, the pattern is:
1. Read `sampleDataSeeded` from the Tenant record (bypass_rls for dashboard page; getTenantPrisma for list pages)
2. Detect `hasSampleRecords` by checking if any fetched row has `isSample === true`
3. If `sampleDataSeeded && hasSampleRecords`, render `<SampleDataBanner tenantId={tenantId} />` at the top of the page JSX (before the header/title section)

**carrier/dashboard/page.tsx:**
- This is a server component with `session.tenantId` available.
- Add a query (after existing session check) to get `sampleDataSeeded` from Tenant:
  ```ts
  const tenant = await prisma.$transaction(async (tx) => {
    await tx.$executeRaw`SELECT set_config('app.bypass_rls', 'on', TRUE)`;
    return tx.tenant.findUnique({ where: { id: orgId }, select: { sampleDataSeeded: true } });
  }, TX_OPTIONS);
  ```
- Import `prisma, TX_OPTIONS` if not already imported.
- For `hasSampleRecords`, do a quick count check (bypass_rls):
  ```ts
  const sampleCount = tenant?.sampleDataSeeded
    ? await prisma.$transaction(async (tx) => {
        await tx.$executeRaw`SELECT set_config('app.bypass_rls', 'on', TRUE)`;
        return tx.truck.count({ where: { tenantId: orgId, isSample: true } });
      }, TX_OPTIONS).catch(() => 0)
    : 0;
  ```
- Render `{tenant?.sampleDataSeeded && sampleCount > 0 && <SampleDataBanner tenantId={orgId} />}` at the top of the returned JSX, above the header `<div>`.
- Import `SampleDataBanner` from `@/components/onboarding/sample-data-banner`.

**trucks/page.tsx and drivers/page.tsx:**

These pages may currently be synchronous server components. Before adding async data fetches for `sampleDataSeeded` and `tenantId`, you MUST convert them to async server components:

- Add the `async` keyword to the page function: `export default async function TrucksPage(...)` and `export default async function DriversPage(...)`.
- If the existing data fetch (e.g. `listTrucks()`, `listDrivers()`) was being called inside an inner sub-component rather than the page function itself, move it into the async page function so the fetched rows are in scope for `hasSampleRecords` detection.
- Alternatively, if `TruckListSection` or `DriverListSection` is already an inner async sub-component that fetches data, render `SampleDataBanner` inside that sub-component where the rows and tenantId are already in scope — this avoids duplicating the fetch at the page level.

For either approach, obtain `tenantId` via `requireTenantId()` or from the session, and `sampleDataSeeded` via:
```ts
const prismaClient = await getTenantPrisma();
const tenant = await prismaClient.tenant.findFirst({ select: { sampleDataSeeded: true } });
```
Note: If `Tenant` is not accessible via the tenant-scoped client, use the bypass_rls pattern instead.

Then:
- `hasSampleRecords = fetchedRows.some(r => r.isSample)` — no extra query, use data already fetched.
- Render `<SampleDataBanner tenantId={tenantId} />` at the top of the page JSX.

**Important:** Do NOT add `isSample=false` to the `findMany` queries that populate the list — sample rows must still appear (with SAMPLE pill).
