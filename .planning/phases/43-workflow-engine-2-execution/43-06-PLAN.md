**Create `apps/mobile/src/screens/workflows/DocumentUploadScreen.tsx`** (spec Section 9.3):

Full-screen, not a modal. Pattern:
- Back button (top left, height 44px)
- Step name (large, 24px bold)
- Instruction text (if available from `stepSnapshot.description`)
- Document type label: `stepSnapshot.documentTypeName ?? 'Document'`
- Upload area: dashed box, height ≥200px, tap to trigger `expo-image-picker`:
  ```typescript
  import * as ImagePicker from 'expo-image-picker'
  
  const pickDocument = async () => {
    const result = await ImagePicker.launchImageLibraryAsync({
      mediaTypes: ImagePicker.MediaTypeOptions.All,
      allowsEditing: false,
      quality: 0.8,
    })
    if (!result.canceled && result.assets[0]) {
      setSelectedFile(result.assets[0])
    }
  }
  ```
  Also offer camera option via `ImagePicker.launchCameraAsync(...)`.
- Thumbnail preview once file selected (use `expo-image` from `expo-image` package — already installed)
- "Replace" button below thumbnail
- `"Submit Document"` button — disabled (`opacity: 0.4, pointerEvents: 'none'`) until `selectedFile !== null` — height 56px, full width, primary brand color
- On submit: upload to S3 via presigned URL then call complete endpoint:
  ```typescript
  // 1. Get presigned upload URL
  const { uploadUrl, s3Key } = await fetch(`${API_BASE_URL}/api/mobile/driver/documents/upload-url`, {
    method: 'POST',
    body: JSON.stringify({ fileName: selectedFile.fileName, contentType: selectedFile.mimeType }),
    headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
  }).then(r => r.json())
  
  // 2. Upload to S3
  await fetch(uploadUrl, {
    method: 'PUT',
    body: await fetch(selectedFile.uri).then(r => r.blob()),
    headers: { 'Content-Type': selectedFile.mimeType ?? 'application/octet-stream' },
  })
  
  // 3. Complete step
  await fetch(`${API_BASE_URL}/api/mobile/driver/tasks/${stepInstanceId}/complete`, {
    method: 'POST',
    body: JSON.stringify({ result: { fileUrls: [s3Key] } }),
    headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
  })
  router.back()
  ```
