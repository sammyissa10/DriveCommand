## What Was Built

**useDriverDirections hook (apps/mobile/hooks/useDriverDirections.ts)**
- TanStack Query wrapper around `driverApi.getDirections`
- Filters stops missing lat/lng before sending to API
- Returns `polyline`, `distanceMiles`, `durationSeconds`, `isLoading`, `isError`
- `staleTime: 5 minutes` — polyline doesn't change mid-route
- `retry: 1` — OSRM public API can be flaky
- `canFetch` guard: requires `enabled` flag + valid token + at least 2 stops with coordinates

**Map screen (apps/mobile/app/(driver)/map.tsx — 296 lines)**
- `MapView` with `styleURL="mapbox://styles/mapbox/standard"` — fills full screen via `StyleSheet.absoluteFill`
- `Camera` with `followUserLocation` + `UserTrackingMode.Follow` enum
- `UserLocation` with `UserLocationRenderMode.Native` enum
- Location permission requested on mount via `expo-location`; denied state shows red banner
- Two-query pattern: `driverApi.getDashboard` (summary) + `driverApi.getLoad` (full stop coords with lat/lng)
- Route polyline via `ShapeSource` + `LineLayer`: `#0ea5e9` sky blue, width 4, round caps/joins
- `MarkerView` per stop with numbered circles: default slate (#475569, 28px), next stop blue (#0ea5e9, 32px), departed green (#22c55e, 70% opacity)
- "No active load" status chip at top center when no active load
- Floating info panel (bottom sheet, `useThemeColors` for surfaceCard background): next stop address, distance in miles, ETA in minutes
- "Start Navigation" CTA button: enabled (blue) when active load + next stop present; disabled (grey, 60% opacity) otherwise
- Navigation deep link logic deferred to Plan 05

- **Fix:** Ran `npm run build` in `packages/api-client` to regenerate dist. Also added `DirectionsResult` to the package index re-exports (it was missing from `src/index.ts`).

**2. [Rule 1 - Bug] Camera and UserLocation props require enum values, not string literals**
- **Found during:** Task 2 (TypeScript check)
- **Issue:** Plan spec used `followUserMode="normal"` and `renderMode="native"` as string literals. Mapbox types require `UserTrackingMode` and `UserLocationRenderMode` enums respectively.
- **Fix:** Imported `UserTrackingMode` and `UserLocationRenderMode` from `@rnmapbox/maps`; replaced string literals with `UserTrackingMode.Follow` and `UserLocationRenderMode.Native`.
- **Files modified:** `apps/mobile/app/(driver)/map.tsx`
- **Commit:** 3212b0a
