### 1. Add screen mount animations
File: apps/mobile/components/ui/AnimatedScreen.tsx

```typescript
import Animated, { FadeIn } from 'react-native-reanimated'

export function AnimatedScreen({ children, style }: { children: React.ReactNode, style?: object }) {
  return (
    <Animated.View entering={FadeIn.duration(200)} style={[{ flex: 1 }, style]}>
      {children}
    </Animated.View>
  )
}
```

Wrap the content (not the ScreenWrapper) in AnimatedScreen on:
- All tab screens (dashboard, loads, HOS, messages, documents for driver; dashboard, map, loads, drivers, fleet for owner)
- Stack screens (load detail, driver detail, incident form)

Do NOT animate: login screen (immediate is better for auth), bottom sheets (have their own animation).

### 3. Add haptic feedback comprehensively
File: apps/mobile/lib/haptics.ts

```typescript
import * as Haptics from 'expo-haptics'

export const haptic = {
  light: () => Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light),
  medium: () => Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium),
  success: () => Haptics.notificationAsync(Haptics.NotificationFeedbackType.Success),
  error: () => Haptics.notificationAsync(Haptics.NotificationFeedbackType.Error),
  warning: () => Haptics.notificationAsync(Haptics.NotificationFeedbackType.Warning),
}
```

Apply haptics:
- Tab bar presses: add onPress to each Tabs.Screen with haptic.light()
- Status update confirm (load): haptic.success() ✓ (already in Phase 31)
- HOS status change confirm: haptic.medium()
- Incident submit success: haptic.success()
- Document upload success: haptic.success()
- Any API error toast: haptic.error()
- Cancel load (destructive): haptic.warning()
- Pull-to-refresh trigger: haptic.light() (in onRefresh)

### 4. Dark mode verification pass
The app is dark-first. Verify light mode also works (system setting):

Check every screen with system appearance set to Light:
- All bg-slate-800/900 → should be bg-white/slate-50 in light mode via dark: variants
- All text-white → should be text-slate-900 in light mode
- Status bar: set to dark-content in light mode, light-content in dark mode

Update ScreenWrapper.tsx:
```typescript
import { useColorScheme } from 'react-native'

export function ScreenWrapper({ children, scrollable }) {
  const colorScheme = useColorScheme()
  return (
    <SafeAreaView className={colorScheme === 'dark' ? 'bg-slate-900 flex-1' : 'bg-white flex-1'}>
      <StatusBar style={colorScheme === 'dark' ? 'light' : 'dark'} />
      {scrollable ? <ScrollView>{children}</ScrollView> : children}
    </SafeAreaView>
  )
}
```

Verify NativeWind dark: variants are working (they use system color scheme automatically).
