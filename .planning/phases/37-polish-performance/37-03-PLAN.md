# Phase 37 — Plan 03: Thumb-Friendliness & Navigation Clarity

## Goal
Make every interactive element comfortable for a truck driver using one hand while wearing gloves. Fix tab navigation discoverability, increase tap targets on the most-used elements, and correct brand inconsistencies visible in the real app.

## Prerequisites
- Plan 37-01 complete (touch target audit base)

## Context: What the screenshots revealed

After reviewing actual emulator screenshots (all 6 screens), these issues stand out:
- Tab bars have no labels → drivers can't tell what tabs do without memorizing icons
- LoadCards are `minHeight: 80` → too short for confident one-thumb taps
- Active/History segment toggle uses `py-2` (~36px) → below 44px minimum
- AppHeader avatar is 34×34px → below Apple HIG + Material minimum
- Login CTA uses `#2563eb` (blue-600) — rest of app uses `#0ea5e9` (sky-500), inconsistent branding
- Owner tab uses `Radio` icon for Fleet Messaging → ambiguous without a label

The floating gear icon visible in screenshots is the Expo dev menu — disappears in production builds, no action needed.
