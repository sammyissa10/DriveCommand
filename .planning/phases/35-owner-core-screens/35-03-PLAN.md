# Phase 35 — Plan 03: Owner Driver Management

## Goal
Build the driver management screen showing all drivers with compliance status, and the driver detail screen with contact info, current load, and document compliance.

## Prerequisites
- Plans 35-01 and 35-02 complete

## Tasks

### 1. Create REST endpoints for owner driver management
GET /api/mobile/owner/drivers:
```typescript
// Auth: Bearer → tenantId, OWNER
// Return: {
//   id, name, email, phone, status,
//   currentLoadNumber: string | null,
//   hosStatus: HOSStatus | null,
//   complianceStatus: 'ok' | 'warning' | 'critical',  // computed from docs
//   expiringDocCount: number,
//   expiredDocCount: number,
// }[]
```

GET /api/mobile/owner/drivers/[id]:
```typescript
// Return full driver detail:
// {
//   ...driver,
//   currentLoad: Load | null,
//   documents: DriverDocument[],  // with computed status
//   recentIncidents: Incident[],  // last 3
//   hosStatus: HOSStatus | null,
// }
```

### 2. Build compliance status indicator
Computed from document array:
- CRITICAL (red): any document expired (status === 'EXPIRED')
- WARNING (amber): any document expiring within 30 days (status === 'EXPIRING')
- OK (green): all documents valid or no expiry

### 3. Build owner driver list screen
File: apps/mobile/app/(owner)/drivers.tsx

- FlashList with DriverCard component
- Filter tabs: All / On Duty / Off Duty (horizontal scroll)
- Pull-to-refresh

DriverCard component:
```typescript
// Left: Avatar circle (initials, deterministic color from name)
// Center: Name (H3), status badge + HOS status text
// Right: compliance dot (green/amber/red)
// Below name: current load number or "No active load" (muted)
// Pressable → driver detail screen
```

### 4. Build driver detail screen
File: apps/mobile/app/(owner)/drivers/[id].tsx

Stack navigator for drivers/[id].tsx (create drivers/_layout.tsx).

Sections:
- Header: large avatar, name, status badge
- Current Load card (if assigned): load number, route, status, tap → load detail
- Compliance section:
  - Each document: icon, name, expiry date, status badge
  - No documents: "No compliance documents uploaded"
- Contact section:
  - Email: tap → mailto: deep link
  - Phone: tap → tel: deep link (if phone number exists)
- Quick actions row:
  - "Send Message" button → navigate to /(owner)/fleet with driverId param to pre-select recipient
  - "View All Loads" → navigate to loads list filtered by this driver

### 5. Add navigation to driver detail from dashboard
Driver status chips on the owner dashboard are tappable → navigate to driver detail.
