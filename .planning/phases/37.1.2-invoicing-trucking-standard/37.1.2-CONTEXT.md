# Phase 37.1.2: Invoicing — Trucking Standard - Context

**Gathered:** 2026-04-03
**Status:** Ready for planning

<domain>
## Phase Boundary

Align invoicing with trucking industry standards. Add freight reference fields to Invoice (BOL, PRO, PO numbers, commodity, weight, pieces, loaded miles). Add itemType and unitType enums to InvoiceItem so line items can represent linehaul, fuel surcharge, detention, stop-off, TONU, lumper, and other standard trucking charges with correct unit-based calculation. Update the invoice UI for freight-standard line item entry including FSC auto-calculation. Does NOT change the invoice PDF/send flow or payment tracking.

</domain>

<decisions>
## Implementation Decisions

### Schema: Invoice header fields
Add to `Invoice` model:
- `bolNumber String?` — Bill of Lading number
- `proNumber String?` — Carrier PRO / internal tracking number
- `poNumber String?` — Customer purchase order number
- `commodity String?` — Description of freight being shipped
- `weightLbs Int?` — Gross cargo weight in pounds
- `pieces Int?` — Pallet / unit / skid count
- `loadedMiles Float?` — Billable loaded miles for this invoice

### Schema: InvoiceItem type + unit enums
New enum `InvoiceItemType`:
- `LINEHAUL` — base freight charge
- `FUEL_SURCHARGE` — FSC, percentage of linehaul
- `DETENTION` — driver wait time beyond free period
- `STOP_OFF` — charge per additional stop
- `LAYOVER` — overnight/extended wait
- `TONU` — Truck Order Not Used
- `LUMPER` — unloading labor
- `ACCESSORIAL` — catch-all (overweight permit, hazmat, liftgate, residential, etc.)
- `TAX` — tax line
- `OTHER` — legacy / free-form

New enum `InvoiceItemUnit`:
- `FLAT` — fixed amount (no quantity calculation)
- `PER_MILE` — quantity=miles, unitPrice=rate/mile
- `PER_CWT` — quantity=cwt (weight÷100), unitPrice=rate/cwt
- `PER_PIECE` — quantity=pieces, unitPrice=rate/piece
- `PER_HOUR` — quantity=hours, unitPrice=hourly rate
- `PERCENT` — quantity=percentage, unitPrice=base amount (used for FSC: amount = qty/100 * unitPrice)

Add to `InvoiceItem` model:
- `itemType InvoiceItemType @default(OTHER)`
- `unitType InvoiceItemUnit @default(FLAT)`

Existing fields (`description`, `quantity`, `unitPrice`, `amount`) remain — all still valid for all types.

### FSC auto-calculation logic
- When a FUEL_SURCHARGE line item is added, the UI pre-fills `unitPrice` from the LINEHAUL line item amount on the same invoice
- `amount = (quantity / 100) * unitPrice`
- User can override any field manually

### Invoice UI updates
- Invoice header: add fields for BOL #, PRO #, PO #, Commodity, Weight (lbs), Pieces, Loaded Miles — shown as a "Freight Details" section
- Freight Details section is collapsible (optional fields, don't break existing invoices)
- Line item entry: add item type selector (dropdown with trucking labels), unit type selector
- When itemType = LINEHAUL and unitType = PER_MILE: show "× N miles @ $X/mi" calculation preview
- When itemType = FUEL_SURCHARGE: show "X% of $linehaul = $amount" helper text
- Standard charge buttons: quick-add buttons for common charges (Linehaul, Fuel Surcharge, Detention, Stop-Off) that pre-fill type/unit defaults

### Backward compatibility
- All new fields are nullable / have defaults — existing invoices are unaffected
- `itemType` defaults to `OTHER`, `unitType` defaults to `FLAT` — existing items render identically
- No data migration needed for existing invoice items

### Claude's Discretion
- Exact UI layout of the Freight Details section (form layout, field order)
- Quick-add button placement and styling
- Whether to auto-populate freight details from the linked load (if invoice has a loadId)

</decisions>

<specifics>
## Specific Ideas

- Standard trucking invoice line items in order: Linehaul first, Fuel Surcharge second, then accessorials, then tax
- FSC is always a percentage of the linehaul rate — this is industry standard (indexed to weekly diesel price)
- Detention standard: first 2 hours free, then $75-$150/hr — the UI should make this easy to enter
- TONU (Truck Order Not Used) = flat fee charged when a shipper cancels after the truck is dispatched
- Per-CWT pricing is common for LTL (Less-Than-Truckload) shipments

</specifics>
