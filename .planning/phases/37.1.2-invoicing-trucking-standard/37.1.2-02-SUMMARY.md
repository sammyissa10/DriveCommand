## Decisions Made

- Freight Details section auto-opens if any freight field is pre-populated in initialData (good UX for load-linked invoices)
- loadedMiles threaded from form state into items editor via prop — avoids lifting state or using context
- FSC unitPrice syncs dynamically from the first LINEHAUL item in the items array on every render cycle
- Load auto-populate only pulls commodity/weight/loadedMiles (fields that exist on the Load model); BOL/PRO/PO are invoice-specific and left for manual entry
