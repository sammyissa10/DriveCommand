# Phase 38 — Plan 02: GitHub Actions CI/CD

## Goal
Create GitHub Actions workflows for automated CI (lint + tests on PR) and CD (OTA update on main merge, production build on version tag).

## Prerequisites
- Plan 38-01 complete (EAS configured and working)
- GitHub repository exists and connected to the project

## Tasks

### 1. Add EAS token to GitHub secrets
```bash
# Get EAS token:
eas account:view  # shows your account
# Or: expo login && cat ~/.expo/state.json to get token

# Add to GitHub repo:
# Settings → Secrets → Actions → New repository secret
# Name: EXPO_TOKEN
# Value: your EAS access token
```

### 2. Create PR CI workflow
File: .github/workflows/mobile-ci.yml

```yaml
name: Mobile CI

on:
  pull_request:
    paths:
      - 'apps/mobile/**'
      - 'packages/**'

jobs:
  check:
    name: Lint + Type Check + Tests
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - name: TypeScript check (mobile)
        run: cd apps/mobile && npx tsc --noEmit

      - name: TypeScript check (packages)
        run: npx turbo run build --filter='./packages/*'

      - name: Lint
        run: npx turbo run lint

      - name: Unit tests
        run: npx turbo run test
```

### 3. Create OTA deploy workflow (on main merge)
File: .github/workflows/mobile-ota.yml

```yaml
name: Mobile OTA Update

on:
  push:
    branches: [main]
    paths:
      - 'apps/mobile/**'
      - 'packages/**'

jobs:
  update:
    name: EAS Update (OTA)
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - uses: expo/expo-github-action@v8
        with:
          expo-version: latest
          eas-version: latest
          token: ${{ secrets.EXPO_TOKEN }}

      - name: Publish OTA update
        run: eas update --branch production --message "Deploy from main (${{ github.sha }})"
        working-directory: apps/mobile
```

### 4. Create production build + submit workflow (on version tag)
File: .github/workflows/mobile-release.yml

```yaml
name: Mobile Release

on:
  push:
    tags:
      - 'v*'

jobs:
  build-and-submit:
    name: EAS Build + Submit
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - uses: actions/setup-node@v4
        with:
          node-version: 20
          cache: 'npm'

      - name: Install dependencies
        run: npm ci

      - uses: expo/expo-github-action@v8
        with:
          expo-version: latest
          eas-version: latest
          token: ${{ secrets.EXPO_TOKEN }}

      - name: Build iOS
        run: eas build --platform ios --profile production --non-interactive
        working-directory: apps/mobile

      - name: Build Android
        run: eas build --platform android --profile production --non-interactive
        working-directory: apps/mobile

      - name: Submit iOS to App Store
        run: eas submit --platform ios --profile production --non-interactive --latest
        working-directory: apps/mobile

      - name: Submit Android to Play Store
        run: eas submit --platform android --profile production --non-interactive --latest
        working-directory: apps/mobile
```

### 5. Add web deployment to existing Vercel workflow
Ensure Vercel auto-deploys apps/web on push to main (Vercel handles this automatically if configured with root directory = apps/web).

Add to mobile-ota.yml (run web build check in parallel):
```yaml
  check-web:
    name: Web Build Check
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20, cache: 'npm' }
      - run: npm ci
      - run: npx turbo run build --filter=@drivecommand/web
```
