# Phase 38 — Plan 01: EAS Build Configuration + Code Signing

## Goal
Configure EAS builds for both platforms with managed credentials, run the first production builds for iOS and Android, and verify .ipa and .aab artifacts are generated.

## Prerequisites
- Phase 37 complete (all screens polished and stable)
- EAS account created and logged in: `eas login`
- Apple Developer Program enrolled ($99/year) — user action
- Google Play Console enrolled ($25) — user action

## Tasks

### 1. Link project to EAS
```bash
cd apps/mobile
eas init  # creates EAS project and adds expo.extra.eas.projectId to app.json
```

This generates a projectId that must be added to app.json:
```json
{
  "expo": {
    "extra": {
      "eas": {
        "projectId": "your-project-id-here"
      }
    }
  }
}
```

### 2. Update .eas.json with production config
```json
{
  "cli": { "version": ">= 12.0.0", "appVersionSource": "remote" },
  "build": {
    "development": {
      "developmentClient": true,
      "distribution": "internal",
      "ios": { "simulator": false },
      "android": { "buildType": "apk" },
      "env": { "EXPO_PUBLIC_API_URL": "http://192.168.1.100:3000" }
    },
    "preview": {
      "distribution": "internal",
      "ios": { "resourceClass": "m-medium" },
      "android": { "buildType": "apk" },
      "channel": "preview",
      "env": { "EXPO_PUBLIC_API_URL": "https://drivecommand.vercel.app" }
    },
    "production": {
      "autoIncrement": true,
      "ios": { "resourceClass": "m-medium" },
      "android": { "buildType": "app-bundle" },
      "channel": "production",
      "env": { "EXPO_PUBLIC_API_URL": "https://drivecommand.vercel.app" }
    }
  },
  "submit": {
    "production": {
      "ios": {
        "appleId": "FILL_IN",
        "ascAppId": "FILL_IN",
        "appleTeamId": "FILL_IN"
      },
      "android": {
        "serviceAccountKeyPath": "./google-play-key.json",
        "track": "production"
      }
    }
  }
}
```

Replace FILL_IN values with actual Apple credentials after Phase 39 App Store Connect setup.

### 3. Configure EAS credentials for iOS
```bash
eas credentials --platform ios
# Select: "Use EAS Managed credentials"
# EAS will generate distribution certificate + provisioning profile automatically
# Credentials are stored securely in EAS servers (not in your repo)
```

### 4. Configure EAS credentials for Android
```bash
eas credentials --platform android
# Select: "Use EAS Managed credentials"
# EAS generates and stores the upload keystore
# IMPORTANT: Download and backup the keystore via EAS dashboard
# A lost keystore means you cannot update the app on Play Store
```

### 5. Set EAS secrets for environment variables
```bash
eas secret:create --scope project --name EXPO_PUBLIC_API_URL --value "https://drivecommand.vercel.app"
# Add any other secrets needed for production (API keys, etc.)
```

### 6. Configure EAS Update
```bash
eas update:configure
# Creates eas-update channel mapping in eas.json
```

Add to app.json:
```json
{
  "expo": {
    "updates": {
      "url": "https://u.expo.dev/your-project-id",
      "enabled": true,
      "fallbackToCacheTimeout": 0,
      "checkAutomatically": "ON_LOAD"
    },
    "runtimeVersion": { "policy": "appVersion" }
  }
}
```

### 7. Run first production builds
```bash
# iOS build (uploads to EAS Build, ~20-30 min)
eas build --platform ios --profile production

# Android build (uploads to EAS Build, ~15-20 min)
eas build --platform android --profile production

# Monitor at: https://expo.dev/accounts/[account]/projects/drivecommand/builds
```

### 8. Verify build artifacts
After builds complete:
- iOS: download .ipa, verify it can be installed via TestFlight
- Android: download .aab, verify it passes Play Store validation
