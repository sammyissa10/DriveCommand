**Create apps/mobile/components/driver/workflows/InspectionModeScreen.tsx**

This component receives the full list of INSPECTION_ITEM StepInstances for the playbook instance, manages the card flow, and handles PASS/FAIL actions. Since it's rendered from TaskActionDispatcher which only has a single stepInstanceId, it must first fetch all steps for the playbook instance (not just one).

**Props interface:**
```typescript
interface InspectionModeScreenProps {
  stepInstance: StepInstance  // The initially opened step (from TaskActionDispatcher)
}
```

**Data fetching strategy:**
On mount, call `GET /api/mobile/driver/tasks` (already exists) to get all step instances. Filter to those in the same `playbookInstanceId` where `stepSnapshot.stepType === 'INSPECTION_ITEM'` and `status === 'NOT_STARTED' | 'IN_PROGRESS'`. Sort by the order they appear (use array index from the API response as approximation). Start the card at the step matching the initial `stepInstance.id`.

**Key implementation details:**

1. **Card animation** — use `react-native-reanimated`:
```typescript
import Animated, { useSharedValue, useAnimatedStyle, withTiming, runOnJS } from 'react-native-reanimated'
import { Dimensions } from 'react-native'

const { width: SCREEN_WIDTH } = Dimensions.get('window')
const cardTranslateX = useSharedValue(0)
const cardStyle = useAnimatedStyle(() => ({ transform: [{ translateX: cardTranslateX.value }] }))

function handlePass() {
  haptic.success()
  callPassAPI()  // fire-and-forget async, no need to await for animation
  cardTranslateX.value = withTiming(-SCREEN_WIDTH, { duration: 280 }, (finished) => {
    if (finished) runOnJS(advanceStep)()
  })
}

function advanceStep() {
  cardTranslateX.value = SCREEN_WIDTH  // snap to right (off-screen)
  setCurrentIndex((i) => i + 1)
  cardTranslateX.value = withTiming(0, { duration: 280 })  // slide in
}
```

2. **PASS API call** (`passOrFail: 'pass'`):
```typescript
await fetch(`${API_BASE_URL}/api/mobile/driver/tasks/${step.id}/complete`, {
  method: 'POST',

  headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },

```

3. **FAIL flow** — expand in-card (no slide):
- Tap FAIL: `haptic.error()`, set `failCapture = true` for current step
- Show fail capture UI (no animation needed — simple show/hide with state)
- Photo capture: use `expo-image-picker` (`ImagePicker.launchCameraAsync` or `launchImageLibraryAsync`). On pick: call `/api/mobile/driver/tasks/upload-photo` to get presigned URL, then PUT to R2 directly. Store s3Keys in local state. Show thumbnail + remove X. Up to 3 photos.
- Submit: call `/api/mobile/driver/tasks/[id]/fail` with `{ result: { photoUrls: s3Keys, note } }`. On success: advance to next step (same slide animation).

4. **Photo upload helper** (inline in component or extracted to a local function):
```typescript
async function uploadPhoto(uri: string, token: string, tenantId: string): Promise<string> {
  const filename = `inspection-${Date.now()}.jpg`
  // Get presigned URL
  const res = await fetch(`${API_BASE_URL}/api/mobile/driver/tasks/upload-photo`, {
    method: 'POST',
    body: JSON.stringify({ fileName: filename, contentType: 'image/jpeg', sizeBytes: 1000000 }),
    headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
  })
  const { uploadUrl, s3Key } = await res.json() as { uploadUrl: string; s3Key: string }
  // Upload to R2
  const blob = await fetch(uri).then(r => r.blob())
  await fetch(uploadUrl, { method: 'PUT', body: blob, headers: { 'Content-Type': 'image/jpeg' } })
  return s3Key
}
```
