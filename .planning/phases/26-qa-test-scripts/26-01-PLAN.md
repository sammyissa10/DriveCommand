SECTION 1: Authentication (~6 cases)
- TC-SA-AUTH-001: Login with correct ADMIN_SECRET_KEY
  - Navigate to /admin/login, enter correct ADMIN_SECRET_KEY from .env.local (NEXT_PUBLIC_ADMIN_SECRET or equivalent), click Login
  - Expected: Redirected to /admin-dashboard, admin nav visible
- TC-SA-AUTH-002: Login with wrong key
  - Enter wrong key → Expected: Error message "Invalid admin key" or similar, stay on /admin/login
- TC-SA-AUTH-003: Logout from SysAdmin portal
  - While logged in, click Logout → Expected: Redirected to /admin/login, admin_session cookie cleared
- TC-SA-AUTH-004: Access /admin-dashboard without login
  - Clear cookies, navigate to /admin-dashboard → Expected: Redirected to /admin/login
- TC-SA-AUTH-005: DRIVER role cannot access /admin portal
  - Log in as a driver user (role=DRIVER) via /sign-in → Navigate to /admin-dashboard
  - Expected: Redirected away (to /my-route or /unauthorized), NOT shown admin UI
- TC-SA-AUTH-006: OWNER role cannot access /admin portal
  - Log in as owner user (role=OWNER) via /sign-in → Navigate to /admin-dashboard
  - Expected: Redirected to /admin-support or /unauthorized, NOT shown admin dashboard

SECTION 2: Dashboard (~3 cases)
- TC-SA-DASH-001: Dashboard loads with metrics cards
  - Navigate to /admin-dashboard → Expected: Page loads, shows metrics cards (tenant count, user count, etc.) with numeric values
- TC-SA-DASH-002: Dashboard empty state (if no tenants exist)
  - Only testable on a fresh environment: all count cards show 0
- TC-SA-DASH-003: Dashboard navigation links work
  - Click each nav link (Tenants, Support, Billing) → Expected: Navigates to correct route

SECTION 3: Tenant Management (~14 cases)
- TC-SA-TEN-001: View tenant list (populated)
  - Navigate to /tenants → Expected: Table lists all tenants with Name, Slug, Status, created date columns
- TC-SA-TEN-002: View tenant list (empty state)
  - On fresh environment, /tenants → Expected: Empty state message visible, no table rows
- TC-SA-TEN-003: Create tenant — happy path
  - Navigate to /tenants/new, fill: Name="Test Fleet Co", Slug="test-fleet-co", Owner Email="owner@testfleet.com", click Create
  - Expected: Redirected to /tenants, "Test Fleet Co" in list with status Active
- TC-SA-TEN-004: Create tenant — duplicate slug
  - Navigate to /tenants/new, enter Slug that already exists → click Create
  - Expected: Validation error "Slug already taken" or similar, stays on /tenants/new
- TC-SA-TEN-005: Create tenant — invalid email
  - Enter Name and Slug, enter email="notanemail" → click Create
  - Expected: Validation error on email field, form not submitted
- TC-SA-TEN-006: Create tenant — missing required fields
  - Leave Name blank, fill other fields → click Create
  - Expected: Validation error on Name field
- TC-SA-TEN-007: View tenant detail page
  - From /tenants list, click on a tenant name → Navigate to /tenants/[id]
  - Expected: Shows tenant name, slug, owner info, resource counts (users, trucks, routes)
- TC-SA-TEN-008: Suspend active tenant
  - On /tenants/[id] for an Active tenant, click Suspend (or status change button)
  - Expected: Status badge changes to Suspended, success toast, action button changes to Reactivate
- TC-SA-TEN-009: Reactivate suspended tenant
  - On /tenants/[id] for a Suspended tenant, click Reactivate
  - Expected: Status changes back to Active, success toast
- TC-SA-TEN-010: Filter tenants by status (if filter exists)
  - On /tenants, use status filter to show only Active or Suspended tenants
  - Expected: List filtered to matching tenants only
- TC-SA-TEN-011: Sort tenant list
  - Click Name column header (if sortable) → Expected: List re-sorts alphabetically
- TC-SA-TEN-012: Navigate to billing from tenant detail
  - On /tenants/[id], click "Create Invoice" or billing link (if present)
  - Expected: Navigates to /billing/new with tenantId pre-populated
- TC-SA-TEN-013: Tenant detail shows correct resource counts
  - Create a tenant, add a user and truck via that tenant's owner portal, return to /tenants/[id]
  - Expected: User count and Truck count reflect added resources
- TC-SA-TEN-014: Cannot access another admin's admin-only page as owner
  - Log in as owner, try navigating to /tenants → Expected: Redirect to /admin-support or unauthorized

SECTION 4: Support Tickets (~7 cases)
- TC-SA-SUP-001: View cross-tenant support queue
  - Navigate to /admin-support → Expected: Table shows tickets from ALL tenants, not just one
- TC-SA-SUP-002: Support queue empty state
  - On fresh environment, /admin-support → Expected: Empty state message, no tickets
- TC-SA-SUP-003: Filter support tickets by status
  - Use status filter on /admin-support to filter by Open / In Progress / Closed
  - Expected: Only tickets with matching status shown
- TC-SA-SUP-004: View support ticket detail
  - Click a ticket → Navigate to /admin-support/[id]
  - Expected: Shows full ticket with subject, body, submitter info (tenant name, user name)
- TC-SA-SUP-005: Reply to support ticket
  - On /admin-support/[id], type reply text "Testing admin reply.", click Reply
  - Expected: Reply appears in thread, reply is attributed to admin
- TC-SA-SUP-006: Change ticket status: Open → In Progress
  - On /admin-support/[id], change status to In Progress → Expected: Status badge updates to In Progress
- TC-SA-SUP-007: Change ticket status: In Progress → Closed
  - On /admin-support/[id], change status to Closed → Expected: Status badge updates to Closed

SECTION 5: Billing & Invoicing (~20 cases)
- TC-SA-BILL-001: View billing list (populated)
  - Navigate to /billing → Expected: Table of invoices with columns Invoice #, Tenant, Status, Total, Due Date; stats cards visible
- TC-SA-BILL-002: View billing list (empty state)
  - On fresh environment → Expected: Empty state message, 0 invoices, stats cards show $0
- TC-SA-BILL-003: Create invoice — happy path with line items
  - Navigate to /billing/new, select a Tenant, fill Issue Date=today, Due Date=30 days from today
  - Add line item: Description="Monthly SaaS Fee", Qty=1, Unit Price=299.00
  - Click Create Invoice
  - Expected: Redirected to /billing/[id], invoice shows status DRAFT, line item visible, Total=$299.00
- TC-SA-BILL-004: Create invoice — multiple line items
  - Add 2 line items: "Platform Fee" qty=1 price=$200, "Setup Fee" qty=1 price=$150
  - Expected: Total=$350.00
- TC-SA-BILL-005: Create invoice — missing required fields (no tenant)
  - Leave Tenant field blank, fill other fields → click Create
  - Expected: Validation error, form not submitted
- TC-SA-BILL-006: Create invoice — missing required fields (no due date)
  - Fill all fields except Due Date → click Create
  - Expected: Validation error on Due Date
- TC-SA-BILL-007: Create invoice — with notes and billing period
  - Fill optional Notes field and billing period start/end dates → Create
  - Expected: Invoice detail shows Notes and Billing Period fields
- TC-SA-BILL-008: Create invoice — pre-selected tenant via URL
  - Navigate to /billing/new?tenantId=[valid-id] → Expected: Tenant dropdown pre-populated with that tenant
- TC-SA-BILL-009: View invoice detail
  - From /billing list, click an invoice → Navigate to /billing/[id]
  - Expected: Shows invoice number, status badge, tenant info, line items table, total
- TC-SA-BILL-010: Edit DRAFT invoice — change line item
  - On /billing/[id] with status DRAFT, click Edit → Navigate to /billing/[id]/edit
  - Change Description of first line item → Save
  - Expected: Invoice detail shows updated description, status remains DRAFT
- TC-SA-BILL-011: Edit DRAFT invoice — add new line item
  - On /billing/[id]/edit, click "Add Line Item", fill in new item, Save
  - Expected: Invoice detail shows 2+ line items, total recalculated
- TC-SA-BILL-012: Attempt to edit SENT invoice (blocked)
  - Send an invoice first (TC-SA-BILL-013), then attempt to navigate to /billing/[id]/edit
  - Expected: Edit button not visible OR redirected with "Cannot edit sent invoice" error
- TC-SA-BILL-013: Send invoice (DRAFT → SENT)
  - On /billing/[id] with status DRAFT, click Send Invoice button
  - Expected: Status badge changes to SENT, Send button disappears, Mark Paid button appears
- TC-SA-BILL-014: Mark invoice as paid (SENT → PAID)
  - On /billing/[id] with status SENT, click Mark as Paid
  - Expected: Status badge changes to PAID (green), no further action buttons
- TC-SA-BILL-015: Mark overdue invoice as paid (OVERDUE → PAID)
  - Set a SENT invoice's due date to past date (requires DB edit or seed), navigate to /billing/[id]
  - Expected: Status shows OVERDUE; click Mark as Paid → status changes to PAID
- TC-SA-BILL-016: Void a DRAFT invoice
  - On /billing/[id] with status DRAFT, click Void
  - Expected: Status changes to VOID, line items still visible but no action buttons
- TC-SA-BILL-017: Void a SENT invoice
  - On /billing/[id] with status SENT, click Void
  - Expected: Status changes to VOID
- TC-SA-BILL-018: Cannot void a PAID invoice
  - On /billing/[id] with status PAID, Void button should NOT appear
  - Expected: No Void button visible for PAID invoices
- TC-SA-BILL-019: Billing stats cards reflect correct totals
  - After creating invoices in various statuses, navigate to /billing
  - Expected: Stats cards (Total Outstanding, Total Paid, etc.) show accurate sums
- TC-SA-BILL-020: Create invoice with recurring flag
  - On /billing/new, check "Recurring" toggle if present, fill all fields, Create
  - Expected: Invoice detail shows "Recurring" purple badge

SECTION 6: User Management (~5 cases)
- TC-SA-USR-001: View all users list across tenants
  - Navigate to /admin-users (or equivalent user management page in the SysAdmin portal)
  - Expected: Table shows users from ALL tenants, not scoped to a single tenant. Columns include: Name/Email, Tenant, Role, Status
- TC-SA-USR-002: View user detail — tenant, role, and status
  - From the user list, click on a user's name or row → Navigate to /admin-users/[id] or detail panel
  - Expected: Shows user email, display name, role (OWNER/MANAGER/DRIVER), associated tenant name, account status (active/inactive)
- TC-SA-USR-003: Filter users by tenant
  - On the user management page, use the Tenant filter to select "Test Fleet Co"
  - Expected: List narrows to only users belonging to "Test Fleet Co"
- TC-SA-USR-004: Deactivate a user
  - On /admin-users/[id] for an active user (non-admin), click Deactivate (or toggle Active to Inactive)
  - Expected: User status badge changes to Inactive, success toast shown; user can no longer log in
- TC-SA-USR-005: Cannot delete or deactivate a SysAdmin/primary admin user (negative)
  - On the user management page, locate a user with admin-level access (or the account used to log in)
  - Expected: Deactivate/Delete button is either absent, disabled, or returns an error such as "Cannot deactivate admin accounts"
