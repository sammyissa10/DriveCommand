**2. [Rule 1 - Bug] Removed invalid 'completed' status filter**
- **Found during:** Task 1 (TypeScript check of maintenance.tsx)
- **Issue:** Code filtered `services.filter(s => s.status !== 'completed')` but ScheduledServiceSummary.status type is `'overdue' | 'due_soon' | 'ok'` — 'completed' has no overlap, TS2367 error
- **Fix:** Changed to `services ?? []` — completed services are never returned by the API (they become MaintenanceEvents), so the filter was unnecessary
- **Files modified:** apps/mobile/app/(owner)/more/maintenance.tsx
- **Verification:** No type errors after fix
- **Committed in:** 566dcdc (Task 1 commit)
