   - Validate Bearer token, require OWNER role, apply rate limit (same pattern as GET above it).

   - Inside prisma.$transaction with bypass_rls:
     a. Verify driver belongs to tenant: `tx.driver.findFirst({ where: { id: driverId, tenantId } })` — return 400 if not found.

     c. Derive origin from first stop address, destination from last stop address.
     d. Create route: `tx.route.create({ data: { tenantId, name, driverId, truckId, status: 'PLANNED', origin, destination, scheduledDate: scheduledDate ? new Date(scheduledDate) : new Date(), stops: { create: stops.map((s, i) => ({ tenantId, position: i + 1, type: s.type, address: s.address, status: 'PENDING', scheduledAt: s.scheduledAt ? new Date(s.scheduledAt) : null, notes: s.notes ?? null })) } } })`.
     e. Return 201 with `{ route: { id, name, status } }`.
   - Wrap in try/catch, log errors with logger.error, return 500 on failure.
