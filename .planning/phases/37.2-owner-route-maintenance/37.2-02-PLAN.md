1. Create `apps/web/src/app/api/mobile/owner/trucks/[id]/scheduled-service/route.ts` with GET, POST, PATCH:

   **GET** — returns scheduled services for this truck:
   - Auth: validateMobileToken, OWNER role, rate limit.
   - Prisma query: `scheduledService.findMany({ where: { tenantId, truckId: id, isCompleted: false }, orderBy: { createdAt: 'desc' } })`.
   - For each service, compute and return user-friendly fields:
     - `dueDate`: if intervalDays set, `baselineDate + intervalDays` days. Else null.
     - `dueMileage`: if intervalMiles set, `baselineOdometer + intervalMiles`. Else null.
     - `status`: 'overdue' if dueDate < now OR (dueMileage needs truck.odometer — fetch truck once and compare, dueMileage < truck.odometer). 'due_soon' if dueDate within 7 days OR dueMileage within 500 miles of truck.odometer. Otherwise 'ok'.
   - Fetch the truck's current odometer once at the start: `tx.truck.findUnique({ where: { id, tenantId }, select: { odometer: true } })`.
   - Return 200 with `{ services: [...] }`.

   **POST** — create a scheduled service:
   - Auth: same pattern.
   - Body: `{ serviceType: string, dueDate?: string, dueMileage?: number, notes?: string }`. At least one of dueDate or dueMileage required.
   - Validate serviceType is non-empty.
   - Fetch truck to get current odometer: `tx.truck.findUnique({ where: { id, tenantId }, select: { odometer: true } })`.
   - Convert user-friendly inputs to model fields:
     - If dueDate provided: `baselineDate = new Date()`, `intervalDays = Math.ceil((new Date(dueDate) - Date.now()) / (86400000))`. Minimum 1 day.
     - If dueMileage provided: `baselineOdometer = truck.odometer`, `intervalMiles = Math.max(1, dueMileage - truck.odometer)`.
     - If neither provided: return 400.
   - Create: `tx.scheduledService.create({ data: { tenantId, truckId: id, serviceType, intervalDays, intervalMiles, baselineDate: new Date(), baselineOdometer: truck.odometer, notes } })`.
   - Return 201 with `{ service: { id, serviceType } }`.

   **PATCH** — mark a scheduled service complete:
   - Auth: same pattern.
   - Body: `{ serviceId: string, actualDate?: string, actualOdometer?: number }`.
   - In transaction:
     a. Find the scheduled service: `tx.scheduledService.findFirst({ where: { id: serviceId, tenantId, truckId: id, isCompleted: false } })`. Return 404 if not found.
     b. Update: `tx.scheduledService.update({ where: { id: serviceId }, data: { isCompleted: true, completedAt: new Date() } })`.
     c. Create a MaintenanceEvent as audit trail: `tx.maintenanceEvent.create({ data: { tenantId, truckId: id, serviceType: service.serviceType, serviceDate: actualDate ? new Date(actualDate) : new Date(), odometerAtService: actualOdometer ?? service.baselineOdometer } })`.
   - Return 200 with `{ success: true }`.

2. Create `apps/web/src/app/api/mobile/owner/maintenance/route.ts` with GET:
   - Auth: validateMobileToken, OWNER role, rate limit.
   - Fetches ALL non-completed scheduled services across all trucks for this tenant.
   - Query: `tx.scheduledService.findMany({ where: { tenantId, isCompleted: false }, include: { truck: { select: { id: true, make: true, model: true, licensePlate: true, odometer: true } } }, orderBy: { createdAt: 'desc' } })`.
   - Compute dueDate, dueMileage, status for each (same logic as per-truck endpoint, using included truck.odometer).
   - Return 200 with `{ services: [...] }` where each service includes truck info + computed status fields.

2. In `packages/api-client/src/owner.ts`, add types:
   ```typescript
   export interface ScheduledServiceSummary {
     id: string
     serviceType: string
     dueDate: string | null
     dueMileage: number | null
     status: 'overdue' | 'due_soon' | 'ok'
     notes: string | null
     createdAt: string
   }

   export interface ScheduledServiceWithTruck extends ScheduledServiceSummary {
     truck: { id: string; make: string; model: string; licensePlate: string; odometer: number }
   }

   export interface CreateScheduledServicePayload {
     serviceType: string
     dueDate?: string
     dueMileage?: number
     notes?: string
   }

   export interface CompleteScheduledServicePayload {
     serviceId: string
     actualDate?: string
     actualOdometer?: number
   }
   ```

3. Add methods to ownerApi object:
   ```typescript
   getScheduledServices: (token: string, truckId: string) =>
     apiRequest<{ services: ScheduledServiceSummary[] }>(
       `/api/mobile/owner/trucks/${truckId}/scheduled-service`, { token }
     ).then(r => r.services),

   createScheduledService: (token: string, truckId: string, payload: CreateScheduledServicePayload) =>
     apiRequest<{ service: { id: string; serviceType: string } }>(
       `/api/mobile/owner/trucks/${truckId}/scheduled-service`,
       { method: 'POST', token, body: JSON.stringify(payload) }
     ),

   completeScheduledService: (token: string, truckId: string, payload: CompleteScheduledServicePayload) =>
     apiRequest<{ success: boolean }>(
       `/api/mobile/owner/trucks/${truckId}/scheduled-service`,
       { method: 'PATCH', token, body: JSON.stringify(payload) }
     ),

   getAllScheduledServices: (token: string) =>
     apiRequest<{ services: ScheduledServiceWithTruck[] }>(
       '/api/mobile/owner/maintenance', { token }
     ).then(r => r.services),
   ```
