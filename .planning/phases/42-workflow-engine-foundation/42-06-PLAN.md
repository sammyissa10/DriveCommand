<objective>
Build the core UX of Phase 42: the Playbook Builder. A 3-column screen where an owner assembles a Playbook by dragging StepTemplates from a library panel into phase sections on a canvas, reordering via drag-and-drop (within AND across phases), and configuring each step's overrideConfig via a right-side slide-in editor.     Save wiring:
    ```tsx
    const trpc = useTRPC();
    const queryClient = useQueryClient();
    const [config, setConfig] = useState<Record<string, any>>(selectedStep.overrideConfig ?? {});

    const updateStepMutation = useMutation(
      trpc.workflows.playbook.updateStep.mutationOptions({
        onSuccess: () => {
          queryClient.invalidateQueries({
            queryKey: trpc.workflows.playbook.getById.queryKey({ id: playbookId }),
          });
          toast.success('Step saved');
        },
        onError: (err) => toast.error(err.message ?? 'Failed to save step'),
      }),
    );

    function handleSave() {
      updateStepMutation.mutate({
        playbookId,
        stepId: selectedStep.id,
        overrideConfig: config,
      });
    }
    ```
