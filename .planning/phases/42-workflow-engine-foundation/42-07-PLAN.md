    BANNED NAMES (from spec Section 3 — do NOT appear in user-facing UI):
    - `PlaybookInstance`
    - `StepInstance`
    - `PlaybookTrigger`

    Intentionally NOT banned (these ARE allowed in UI per spec):
    - `StepTemplate` — spec's Section 3 says "Step Template" IS a user-facing term. Safe.
    - `Playbook` — user-facing.
    - "Checklists & Workflows" — the intended UI label.

    PITFALL (RESEARCH.md Pitfall 5): Do NOT use a naive regex. TypeScript `import { PlaybookInstance } from '@prisma/client'` will trigger false positives. The regex must target JSX text and attribute string values only.

    APPROACH:
    1. Scan all `.tsx` files under `apps/web/src/app/(owner)/checklists/` recursively (use Node `fs.readdirSync` + `path` + recursion, or use fast-glob if already installed — otherwise stick to fs).
    2. For each file, read as text.
    3. Strip out lines that are IMPORT or TYPE declarations:
       - Lines starting with `import `
       - Lines inside `interface X {` through its matching `}` (heuristic: any line starting with `type ` or `interface `)
       - Better: strip all lines matching `/^\s*(import|export\s+(type|interface))\s/` — simple and effective.
       - Also strip lines matching `^\s*\*` (JSDoc inside block comments).
    4. On remaining lines, check if any banned name appears between `>` and `<` (JSX text) OR inside a JSX string attribute (`"..."` on a `<Component attr="...">` style attribute).
    5. Use a simpler, more robust regex:
       ```javascript
       const BANNED = ['PlaybookInstance', 'StepInstance', 'PlaybookTrigger'];
       const jsxTextRegex = /(>[^<>]*?\b(?:PlaybookInstance|StepInstance|PlaybookTrigger)\b[^<>]*?<)/;
       const stringAttributeRegex = /=\s*["']([^"']*?\b(?:PlaybookInstance|StepInstance|PlaybookTrigger)\b[^"']*?)["']/;
       ```
    6. For each violation, record file path + line number + matched text. Fail the test with a readable error.

    Test structure:
    ```typescript
    import { describe, it, expect } from 'vitest';
    import { readFileSync, readdirSync, statSync } from 'fs';
    import { join } from 'path';

    const OWNER_CHECKLISTS_DIR = join(process.cwd(), 'src/app/(owner)/checklists');
    const BANNED_NAMES = ['PlaybookInstance', 'StepInstance', 'PlaybookTrigger'];

    function walk(dir: string, files: string[] = []): string[] {
      for (const entry of readdirSync(dir)) {
        const full = join(dir, entry);
        const stat = statSync(full);
        if (stat.isDirectory()) walk(full, files);
        else if (full.endsWith('.tsx')) files.push(full);
      }
      return files;
    }

    function stripImportsAndTypes(source: string): string {
      return source
        .split('\n')
        .map((line) =>
          /^\s*(import\s|export\s+(type|interface)\s|type\s|interface\s)/.test(line) || /^\s*\*/.test(line)
            ? ''
            : line
        )
        .join('\n');
    }

    describe('Workflows naming lint (spec Section 3)', () => {
      it('does not surface internal names in rendered JSX of the owner checklists route', () => {
        const files = walk(OWNER_CHECKLISTS_DIR);
        const violations: Array<{ file: string; line: number; text: string; name: string }> = [];

        for (const file of files) {
          const source = readFileSync(file, 'utf8');
          const cleaned = stripImportsAndTypes(source);
          const lines = cleaned.split('\n');
          for (let i = 0; i < lines.length; i++) {
            const line = lines[i];
            for (const name of BANNED_NAMES) {
              if (!line.includes(name)) continue;
              const inJsxText = new RegExp(`>[^<>]*${name}[^<>]*<`).test(line);
              const inStringAttr = new RegExp(`=\\s*["'][^"']*${name}[^"']*["']`).test(line);
              if (inJsxText || inStringAttr) {
                violations.push({ file, line: i + 1, text: line.trim(), name });
              }
            }
          }
        }

        if (violations.length > 0) {
          const msg = violations
            .map((v) => `  ${v.file}:${v.line}  [${v.name}]  ${v.text}`)
            .join('\n');
          throw new Error(
            `Internal workflow names leaked into UI — use user-facing names from spec Section 3:\n${msg}`
          );
        }
        expect(violations.length).toBe(0);
      });
    });
    ```
