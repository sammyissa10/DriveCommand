Purpose: Allow DriveCommand team to access the admin portal without needing a user account in any tenant's database. Gradual migration path alongside existing isSystemAdmin() mechanism.

  <action>
    Create `src/lib/auth/admin-session.ts` using the same AES-256-GCM Web Crypto pattern from `src/lib/auth/session.ts`. Key differences:
    - Uses `ADMIN_SECRET_KEY` env var (not `AUTH_SECRET`) — throws if missing or under 32 chars
    - Cookie name: `admin_session` (constant exported as `ADMIN_SESSION_COOKIE = 'admin_session'`)
    - Expiry: 8 hours (`8 * 60 * 60` seconds)
    - Payload type: `AdminSessionData { loggedInAt: number }` (minimal — no user identity needed)
    - Export: `encryptAdminSession(payload: AdminSessionData): Promise<string>`, `decryptAdminSession(token: string | undefined): Promise<AdminSessionData | null>`, `setAdminSession(): Promise<void>`, `clearAdminSession(): Promise<void>`, `getAdminSession(): Promise<AdminSessionData | null>`
    - `getAdminSession` reads from `cookies()` and calls `decryptAdminSession`, also validates `loggedInAt` age < 8 hours as defense-in-depth
    - Wrap with `cache()` from React like `getSession` does

    Create `src/app/api/admin/login/route.ts` (Edge-compatible, use `export const runtime = 'nodejs'` since it uses `cookies()`):
    - POST handler: read `password` from JSON body
    - Compare: `password === process.env.ADMIN_SECRET_KEY` (plain string compare — brute-force resistance comes from password complexity, not rate-limiting for v1)
    - On match: call `setAdminSession()`, return 200 `{ success: true }`
    - On mismatch: return 401 `{ error: 'Invalid password' }` with 500ms delay (`await new Promise(r => setTimeout(r, 500))`) to slow brute force
    - On missing env var: return 500 `{ error: 'Admin auth not configured' }`

    Create `src/app/api/admin/logout/route.ts`:
    - GET handler: call `clearAdminSession()`, redirect to `/admin/login` using `NextResponse.redirect`
    - Add `/api/admin/login` and `/api/admin/logout` to `PUBLIC_PATHS` in middleware so unauthenticated requests can reach them
  </action>
  <verify>
    Run `npx tsc --noEmit` — no TypeScript errors.
    Test: `curl -s -X POST http://localhost:3000/api/admin/login -H "Content-Type: application/json" -d '{"password":"wrong"}' -w "\n%{http_code}"` returns 401.
  </verify>
  <done>
    `src/lib/auth/admin-session.ts` exports encryptAdminSession, decryptAdminSession, setAdminSession, clearAdminSession, getAdminSession, ADMIN_SESSION_COOKIE. Login route returns 200 on correct key and 401 on wrong key. Logout route clears cookie and redirects.
