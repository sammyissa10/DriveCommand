  <name>Task 1: getSystemMetrics + getTenantById server actions</name>
  <files>
    src/app/(admin)/actions/tenants.ts
  </files>
  <action>
    Add two new exported server actions to the existing `src/app/(admin)/actions/tenants.ts` file. Both must call `requireSystemAdmin()` first.

    **`getSystemMetrics()`:**
    Uses base `prisma` (not getTenantPrisma) for cross-tenant queries. All queries run in parallel with `Promise.all`:
    - `totalTenants`: `prisma.tenant.count()`
    - `activeLoadsToday`: `prisma.load.count({ where: { status: { in: ['DISPATCHED', 'PICKED_UP', 'IN_TRANSIT'] }, createdAt: { gte: startOfDay } } })` where startOfDay is midnight UTC today (`new Date(new Date().setUTCHours(0,0,0,0))`)
    - `newSignupsThisWeek`: `prisma.tenant.count({ where: { createdAt: { gte: sevenDaysAgo } } })` where sevenDaysAgo is `new Date(Date.now() - 7 * 24 * 60 * 60 * 1000)`
    - `openTickets`: `prisma.supportTicket.count({ where: { status: 'OPEN' } })`
    Return: `{ totalTenants, activeLoadsToday, newSignupsThisWeek, openTickets }`

    **`getTenantById(tenantId: string)`:**
    Fetches a single tenant with full detail:
    ```ts
    prisma.tenant.findUnique({
      where: { id: tenantId },
      select: {
        id: true,
        name: true,
        slug: true,
        isActive: true,
        createdAt: true,
        updatedAt: true,
        _count: { select: { users: true, trucks: true, routes: true } },
        users: {
          where: { role: 'OWNER' },
          select: { id: true, email: true, firstName: true, lastName: true, createdAt: true },
          take: 1,
        },
        driverInvitations: {
          where: { role: 'OWNER', status: 'PENDING' },
          select: { id: true, email: true, firstName: true, lastName: true, createdAt: true, expiresAt: true },
          take: 1,
        },
      },
    })
    ```
    Return the result mapped to include `ownerSetupComplete: tenant.users.length > 0`, `ownerUser: tenant.users[0] ?? null`, `pendingOwnerInvitation: tenant.driverInvitations[0] ?? null`.
    If `findUnique` returns null (tenant not found), throw `new Error('Tenant not found')`.
  </action>
  <verify>
    Run `npx tsc --noEmit` — no TypeScript errors in actions/tenants.ts.
  </verify>
  <done>
    `getSystemMetrics` and `getTenantById` are exported from actions/tenants.ts and compile without errors.
  </done>
