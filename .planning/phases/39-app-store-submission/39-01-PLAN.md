# Phase 39 — Plan 01: Store Assets (Icon, Screenshots, Feature Graphic)

## Goal
Produce all visual assets required for App Store and Google Play submission: app icon, screenshots on correct device sizes, and Android feature graphic.

## Prerequisites
- Phase 38-03 complete (beta testing done, app is stable)
- Physical devices available for screenshots (or simulator for clean screenshots)
- Demo account with realistic seeded data

## Tasks

### 1. App icon
File: apps/mobile/assets/images/icon.png

Requirements:
- 1024×1024 pixels
- PNG format, no transparency (stores apply rounding mask)
- No alpha channel
- Content: DriveCommand DC chevron logo, centered, on solid #0f172a background
- Must look good at small sizes (will be shown at 60×60 on device)

Generate from existing logo assets:
- Use the existing DriveCommand logo SVG (in public/ from Phase 87)
- Scale to 1024×1024 with appropriate padding (logo at ~60% of canvas size)
- Export as PNG with no transparency

Also create:
- adaptive-icon.png (1024×1024, Android adaptive icon foreground — same logo, transparent background)
- notification-icon.png (96×96, Android notification icon — white/transparent only)

### 2. Capture screenshots
Take screenshots using Expo dev build on physical device or iOS Simulator.

Ensure demo account has realistic data:
- 3 active loads with origin/destination cities
- 2 drivers on duty with HOS status
- GPS positions set for vehicles
- A few fleet messages

iPhone 6.7" screenshots (1290×2796 or 1320×2868):
1. Login screen (DriveCommand branding)
2. Driver Dashboard (active load card visible, stats showing)
3. Driver Load Detail (load with 3 stops, timeline visible)
4. Driver HOS screen (showing DRIVING status, clocks)
5. Owner Dashboard (KPIs, driver status grid)
6. Owner Live Map (vehicles with colored markers)

iPhone 6.5" screenshots: same 6 screens at 1242×2688.
iPad 12.9" screenshots: same screens at 2048×2732.
Android screenshots: same 6 screens at 1080×1920.

Tools for screenshots:
- iOS Simulator: Device → Trigger Screenshot (saves to ~/Desktop)
- Physical device: Hardware button combination (saves to Photos)
- Android emulator: camera icon in emulator toolbar

### 3. Android feature graphic
Size: 1024×500 PNG

Design:
- Dark background (#0f172a)
- DriveCommand logo left-aligned
- Tagline right: "Fleet Management for Truckers"
- Can use a screenshot composite behind a subtle overlay
- Create with Canva, Figma, or any design tool

### 4. Screenshot annotation (optional but professional)
Overlay text above/below each screenshot to explain what's shown:
- "Track active loads in real time"
- "Log duty status with a tap"
- "See your entire fleet on one map"

Use a consistent font (Poppins) and brand color (#0ea5e9).

Tools: Canva, Figma, or a simple Node script using sharp/jimp.
