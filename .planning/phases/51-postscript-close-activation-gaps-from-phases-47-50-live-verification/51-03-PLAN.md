# Plan 51-03: Wire checklist CTAs to actionable URLs

## Goal
Make incomplete checklist items clickable links to the relevant create pages so users can act directly from the onboarding checklist without hunting through the nav.

## must_haves
- [ ] Incomplete checklist items are wrapped in `<Link>` with the correct `href`
- [ ] Completed (checked/strikethrough) items are NOT wrapped in `<Link>` — they remain plain `<li>` rows
- [ ] Item 1 (Account created) is never linked — it is always complete
- [ ] Item 3 label is updated from "Invite your first driver" to "Add your first driver"
- [ ] Incomplete items show `cursor-pointer` and a hover background on the `<li>` row
- [ ] `Link` is already imported in this file (confirmed — line 5 of current file)
- [ ] Dark mode variants are applied where hover background is added
- [ ] TypeScript compiles cleanly (npx tsc --noEmit, no lint)

## Context
The `ActivationChecklist` component in `checklist.tsx` renders 5 items as plain `<li>` rows with no interactivity. Users who see "Add your first truck" have no affordance to navigate there. The component already imports `Link` from `next/link` (line 5) and `Button` from shadcn/ui (line 4). The `items` array is built at render time and currently has no `href` field. The fix is to add an optional `href` field to `ChecklistItem` and conditionally wrap the row content in a `<Link>`.

  { label: 'Add your first driver', complete: firstRealDriverAt !== null, href: '/carrier/fleet/drivers/new' },

**3. Update the `<li>` render inside the `<ul>` map:**

Replace the current `<li>` block with a conditional render:
```tsx
{items.map((item) => {
  const rowContent = (
    <>
      {item.complete ? (
        <CheckCircle2 className="h-5 w-5 text-emerald-500 shrink-0" />
      ) : (
        <Circle className="h-5 w-5 text-muted-foreground/40 shrink-0" />
      )}
      <span
        className={
          item.complete
            ? 'text-sm line-through text-muted-foreground'
            : 'text-sm text-foreground'
        }
      >
        {item.label}
      </span>
    </>
  );

  if (!item.complete && item.href) {
    return (
      <li key={item.label}>
        <Link
          href={item.href}
          className="flex items-center gap-3 py-2 rounded-md px-1 -mx-1 cursor-pointer hover:bg-muted/50 dark:hover:bg-muted/30 transition-colors"
        >
          {rowContent}
        </Link>
      </li>
    );
  }

  return (
    <li key={item.label} className="flex items-center gap-3 py-2">
      {rowContent}
    </li>
  );
})}
```

Use existing Tailwind + shadcn/ui patterns from the file. Preserve the `space-y-0.5` class on the `<ul>`.
