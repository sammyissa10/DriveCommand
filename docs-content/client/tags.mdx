# Tags & Labels

<Callout variant="info">
Tags are color-coded labels you can apply to trucks and drivers for organization, filtering, and reporting. Use tags to group assets by region, customer type, maintenance status, or any custom category.
</Callout>

## Overview

The tagging system helps you organize fleet assets with visual labels:

- **Color-coded badges** — 12 preset colors to choose from
- **Custom names** — create tags for any purpose
- **Multi-entity support** — apply tags to trucks and drivers
- **Filter views** — quickly find tagged assets
- **Reporting** — group reports by tag

<PlanBadge tier="free" /> This feature is available on all plans.

## Create a tag

<StepFlow>
  <StepFlow.Step title="Navigate to Tags">
    In the sidebar, click **Tags** under Legacy Features.
  </StepFlow.Step>
  <StepFlow.Step title="Click New Tag">
    The tag creation form appears.
  </StepFlow.Step>
  <StepFlow.Step title="Choose a name">
    Enter a descriptive tag name (e.g., "East Coast", "High Priority", "Under Maintenance").
  </StepFlow.Step>
  <StepFlow.Step title="Select a color">
    Pick from 12 preset colors. Choose colors that create visual contrast for quick scanning.
  </StepFlow.Step>
  <StepFlow.Step title="Save the tag">
    Click **Save**. The tag is now available to apply to trucks and drivers.
  </StepFlow.Step>
</StepFlow>

<Callout variant="tip" title="Pro Tip">
Use consistent color schemes across your organization. For example, use blue for regional tags, green for status tags, and orange for priority tags.
</Callout>

## Apply tags to trucks

Add tags to trucks from the truck list or detail page:

**From truck list:**

1. Select one or more trucks using checkboxes
2. Click **Bulk Actions → Apply Tag**
3. Select tag from dropdown
4. Click **Apply**

**From truck detail page:**

1. Open the truck detail page
2. Scroll to **Tags** section
3. Click **Add Tag**
4. Select tag from dropdown
5. Click **Apply**

Trucks can have multiple tags. Tags appear as colored badges next to the truck name.

## Apply tags to drivers

Add tags to drivers from the driver list or detail page:

**From driver list:**

1. Select one or more drivers using checkboxes
2. Click **Bulk Actions → Apply Tag**
3. Select tag from dropdown
4. Click **Apply**

**From driver detail page:**

1. Open the driver detail page
2. Scroll to **Tags** section
3. Click **Add Tag**
4. Select tag from dropdown
5. Click **Apply**

Drivers can have multiple tags. Tags appear as colored badges next to the driver name.

## Filter by tags

Use tags to filter truck and driver lists:

1. Navigate to the truck or driver list
2. Click the **Filter** icon
3. Select **Tags** filter
4. Choose one or more tags
5. The list updates to show only tagged assets

Combine tag filters with other filters (status, availability, region) for precise searches.

## Common tag use cases

**Regional tags:**

- "East Coast", "West Coast", "Midwest"
- Helps dispatch drivers in the right geography

**Customer-specific tags:**

- "Amazon Dedicated", "Walmart Lanes", "Regional LTL"
- Assign trucks to specific customer contracts

**Status tags:**

- "Under Maintenance", "Lease Expiring", "High Mileage"
- Track asset lifecycle and maintenance needs

**Priority tags:**

- "VIP Driver", "High Value Truck", "Preferred Equipment"
- Identify premium assets for special loads

**Compliance tags:**

- "Expiring Docs", "HazMat Certified", "Oversize Permitted"
- Track certifications and compliance needs

<Callout variant="success">
Create tags that match your business workflows. There's no right or wrong way to use tags — they're flexible to fit your needs.
</Callout>

## Edit or delete tags

**To edit a tag:**

1. Navigate to **Tags**
2. Click the tag in the list
3. Change name or color
4. Click **Save**

All trucks and drivers with that tag update automatically.

**To delete a tag:**

1. Navigate to **Tags**
2. Click the tag in the list
3. Click **Delete Tag**
4. Confirm deletion

The tag is removed from all trucks and drivers.

<Callout variant="warning" title="Important">
Deleting a tag cannot be undone. The tag is permanently removed from all assets.
</Callout>

## Frequently asked questions

**How many tags can I create?**

There's no limit. Create as many tags as you need to organize your fleet.

**Can I apply multiple tags to one truck or driver?**

Yes. Assets can have unlimited tags. Apply as many as needed for accurate categorization.

**Do tags affect dispatch or load assignment?**

No. Tags are for organization and filtering only. They don't restrict which trucks or drivers can be assigned to loads.

**Can I export a list of assets by tag?**

Yes. Filter the truck or driver list by tag, then click **Export** to download a CSV with only tagged assets.
