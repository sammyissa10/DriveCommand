# Carrier Dashboard

<Callout variant="info">
The Carrier Dashboard gives you a real-time view of your entire operation with key performance indicators, active loads, driver status, and fleet health metrics.
</Callout>

## What this is

Your operations command center. The Carrier Dashboard displays critical metrics like today's revenue, active loads, available drivers, and compliance alerts. It provides instant visibility into what's happening across your fleet right now, helping you make quick dispatch decisions and spot issues before they become problems.

Unlike individual feature pages, the dashboard aggregates data from across DriveCommand to give you a complete operational snapshot in one place.

## How to use it

<StepFlow>
  <StepFlow.Step title="Access the dashboard">
    Navigate to **Carrier → Dashboard** from the main menu. This opens your operations overview.
  </StepFlow.Step>
  <StepFlow.Step title="Review KPI cards">
    The top section shows key metrics: today's revenue, active loads count, available drivers, and compliance issues. Each card updates in real-time as data changes.
  </StepFlow.Step>
  <StepFlow.Step title="Check load status">
    The load status panel shows how many loads are in each stage: PENDING, IN_TRANSIT, DELIVERED. Click any status to filter the full load list.
  </StepFlow.Step>
  <StepFlow.Step title="Monitor driver availability">
    The driver availability section shows which drivers are currently on-duty, available, or off-duty. Green dots indicate active drivers ready for dispatch.
  </StepFlow.Step>
  <StepFlow.Step title="Review fleet health alerts">
    The bottom section highlights upcoming document expirations, trucks due for maintenance, and HOS violations. Address red-flagged items immediately.
  </StepFlow.Step>
</StepFlow>

## Good to know

<Callout variant="tip" title="Pro Tip">
Check the dashboard first thing each morning to prioritize your day. Red compliance alerts should be addressed before dispatching new loads to avoid roadside violations.
</Callout>

The dashboard refreshes automatically every 60 seconds when the browser tab is active. Force a manual refresh by clicking the refresh icon in the top-right corner.
