# Driver Pay Report

<Callout variant="info">
Driver Pay Report summarizes driver compensation by pay period, showing miles driven, loads completed, bonuses earned, and deductions applied.
</Callout>

## What this is

A payroll analytics view for driver compensation. See each driver's total miles, number of loads, base pay, bonuses, deductions, and net pay for any selected pay period. Use this to verify payroll calculations before submitting to your accounting system or to answer driver questions about pay.

<PlanBadge tier="business" /> This feature requires a Business plan or higher.

## How to use it

<StepFlow>
  <StepFlow.Step title="Open the report">
    Go to **Carrier → Reports → Driver Pay**. The default view shows the current pay period.
  </StepFlow.Step>
  <StepFlow.Step title="Select pay period">
    Choose a pay period from the dropdown (weekly, bi-weekly, or custom date range). The report recalculates to show data for that period only.
  </StepFlow.Step>
  <StepFlow.Step title="Review driver totals">
    Each row shows one driver: total miles, load count, base pay, bonus amounts (safety, performance), deductions (fuel advances, insurance), and net pay.
  </StepFlow.Step>
  <StepFlow.Step title="Drill into driver detail">
    Click any driver name to see the itemized breakdown: each load completed, miles per load, per-mile rate, and bonus/deduction line items.
  </StepFlow.Step>
  <StepFlow.Step title="Export for payroll">
    Click **Export CSV** to download the report in a format compatible with QuickBooks, ADP, or other payroll systems.
  </StepFlow.Step>
</StepFlow>

## Good to know

<Callout variant="tip" title="Pro Tip">
Run this report at the end of each pay period to catch data entry errors before processing payroll. If a driver's miles or load count looks unusually low, investigate before issuing paychecks.
</Callout>

Driver pay calculations are based on payroll records created in the Payroll Management feature. If you haven't created payroll records yet, the report will show zero totals.
