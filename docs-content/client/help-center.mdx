# Help Center

<Callout variant="info">
The Help Center is your in-app documentation hub. Find feature guides, video tutorials, and what's new updates without leaving DriveCommand.
</Callout>

## Overview

The Help Center provides self-service resources to learn DriveCommand features:

- **Feature guides** — step-by-step instructions for every feature
- **Video tutorials** — screen recordings showing common workflows
- **What's New** — updates on new features and improvements
- **Search** — quickly find answers to specific questions
- **Related articles** — contextual help based on what you're viewing

<PlanBadge tier="free" /> This feature is available on all plans.

## Navigate the Help Center

Access the Help Center in two ways:

**From the sidebar:**

1. Click the **Help** icon in the sidebar
2. The Help Center opens in a side panel
3. Browse categories or use search

**From contextual help buttons:**

1. Look for the **?** icon on any page
2. Click to open relevant help articles
3. Articles are filtered to the feature you're viewing

## Search for help articles

The fastest way to find answers:

<StepFlow>
  <StepFlow.Step title="Open Help Center">
    Click the Help icon in the sidebar.
  </StepFlow.Step>
  <StepFlow.Step title="Use the search box">
    Type your question or keywords (e.g., "how to invite driver" or "upload truck documents").
  </StepFlow.Step>
  <StepFlow.Step title="Browse results">
    Results appear instantly as you type. Click any article to view full content.
  </StepFlow.Step>
  <StepFlow.Step title="Filter by category">
    Use category filters on the left to narrow results (Dispatch, Fleet, Compliance, etc.).
  </StepFlow.Step>
</StepFlow>

## Browse by category

Help articles are organized into categories matching DriveCommand's feature structure:

- **Carrier Ops** — dispatch, loads, routes, stops
- **Fleet Management** — trucks, drivers, messaging
- **Intelligence** — live map, lane analytics, profit predictor
- **Workflows** — checklists, playbooks, automation
- **Finance** — invoicing, payroll, fuel tracking
- **Compliance** — document tracking, IFTA, safety
- **Settings** — team permissions, integrations, subscription

Click any category to see all articles in that section.

## Watch video tutorials

Many help articles include embedded video tutorials:

1. Open a help article
2. Scroll to find the **Video Tutorial** section
3. Click play to watch
4. Videos include captions for accessibility

Videos cover common workflows like:

- Dispatching your first load
- Inviting and onboarding drivers
- Creating invoices
- Setting up workflows

<Callout variant="tip" title="Pro Tip">
Watch videos at 1.5x speed if you're familiar with the basics. Use the video controls to skip ahead or rewatch specific sections.
</Callout>

## Check What's New

Stay updated on new features and improvements:

1. Open the Help Center
2. Click **What's New** in the top navigation
3. See the latest updates sorted by date

What's New includes:

- **New features** — brand new capabilities added to DriveCommand
- **Improvements** — enhancements to existing features
- **Bug fixes** — resolved issues and performance updates

Each update includes a brief description and links to related help articles.

## Get support

If you can't find an answer in the Help Center:

1. Click **Contact Support** at the bottom of any help article
2. Fill out the support ticket form
3. Attach screenshots if helpful
4. Click **Submit Ticket**

The support team typically responds within 24 hours.

## Frequently asked questions

**Can I access Help Center articles from the mobile app?**

Not currently. The Help Center is web-only. Mobile users can access help articles via their phone's web browser.

**Are help articles updated when features change?**

Yes. Help articles are reviewed and updated regularly. Each article shows a "Last Reviewed" date in the metadata.

**Can I suggest improvements to help articles?**

Yes. Use the **Was this helpful?** feedback widget at the bottom of each article to suggest improvements or report inaccuracies.
