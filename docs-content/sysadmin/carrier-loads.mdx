### `updateLoadStatus()`

Advances load status through the workflow. Enforces forward-only progression.

<CodeBlock language="typescript">
{`export async function updateLoadStatus(
  prevState: ActionState | null,
  formData: FormData
): Promise<ActionState<Load>> {
  await requireRole([UserRole.OWNER, UserRole.MANAGER, UserRole.DRIVER]);
  const tenantId = await requireTenantId();
  const prisma = await getTenantPrisma();

  const parsed = UpdateLoadStatusSchema.parse({
    loadId: formData.get('loadId'),
    newStatus: formData.get('newStatus'),
  });

  const load = await prisma.load.findUnique({
    where: { id: parsed.loadId, tenantId },
  });

  if (!load) {
    return { success: false, error: 'Load not found' };
  }

  // Enforce forward-only status progression
  const statusOrder = ['PENDING', 'ASSIGNED', 'IN_TRANSIT', 'DELIVERED'];
  const currentIndex = statusOrder.indexOf(load.status);
  const newIndex = statusOrder.indexOf(parsed.newStatus);

  if (newIndex <= currentIndex) {
    return { success: false, error: 'Cannot regress load status' };
  }

  const updated = await prisma.load.update({
    where: { id: parsed.loadId },
    data: {
      status: parsed.newStatus,
      updatedAt: new Date(),
    },
  });

  return { success: true, data: updated };
}`}
</CodeBlock>

## Workflow / State Machine

<ProcessDiagram steps={[
  { label: "PENDING", description: "Load created, awaiting route assignment" },
  { label: "ASSIGNED", description: "Route and driver assigned" },
  { label: "IN_TRANSIT", description: "Driver picked up freight" },
  { label: "DELIVERED", description: "Driver delivered freight" }
]} />

**State transitions:**
- PENDING → ASSIGNED: Owner assigns to route via `assignDriver()`
- ASSIGNED → IN_TRANSIT: Driver picks up freight
- IN_TRANSIT → DELIVERED: Driver completes delivery
- **No backwards transitions allowed**
