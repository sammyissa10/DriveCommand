## Overview

AR Aging Report shows overdue invoice totals grouped by aging buckets.

### Aging Bucket Logic

<CodeBlock language="typescript">
{`function categorizeInvoice(invoice: Invoice): AgingBucket {
  const now = new Date();
  const daysOverdue = differenceInDays(now, invoice.dueDate);

  if (daysOverdue < 0) return 'CURRENT';
  if (daysOverdue <= 30) return '1_30_DAYS';
  if (daysOverdue <= 60) return '31_60_DAYS';
  if (daysOverdue <= 90) return '61_90_DAYS';
  return 'OVER_90_DAYS';
}`}
</CodeBlock>
