## Overview

The Subscription Management subsystem handles plan selection (Starter, Pro, Business, Enterprise), billing history, feature availability enforcement, and trial period management.

**Key components:**
- Server actions in `src/actions/settings/subscription.ts`
- Tenant model (subscriptionPlan field)
- Plan tier middleware checks
- Trial expiry cron job

### `upgradePlan()`

Upgrades tenant to a higher plan tier.

<CodeBlock language="typescript">
{`export async function upgradePlan(
  prevState: ActionState | null,
  formData: FormData
): Promise<ActionState<Tenant>> {
  await requireRole([UserRole.OWNER]);
  const tenantId = await requireTenantId();
  const prisma = await getTenantPrisma();

  const parsed = UpgradePlanSchema.parse({
    planTier: formData.get('planTier'), // STARTER | PRO | BUSINESS | ENTERPRISE
  });

  const tenant = await prisma.tenant.update({
    where: { id: tenantId },
    data: {
      subscriptionPlan: parsed.planTier,
      subscriptionStartDate: new Date(),
      trialEndsAt: null, // Clear trial if upgrading
    },
  });

  return { success: true, data: tenant };
}`}
</CodeBlock>

## Plan Tier Enforcement

Middleware checks plan tier before allowing access to features.

<CodeBlock language="typescript">
{`export async function requirePlanTier(minTier: SubscriptionPlan) {
  const tenantId = await requireTenantId();
  const prisma = await getTenantPrisma();

  const tenant = await prisma.tenant.findUnique({
    where: { id: tenantId },
    select: { subscriptionPlan: true },
  });

  const tierHierarchy = ['FREE', 'STARTER', 'PRO', 'BUSINESS', 'ENTERPRISE'];
  const currentTierIndex = tierHierarchy.indexOf(tenant.subscriptionPlan);
  const requiredTierIndex = tierHierarchy.indexOf(minTier);

  if (currentTierIndex < requiredTierIndex) {
    throw new Error(\`This feature requires \${minTier} plan or higher\`);
  }
}`}
</CodeBlock>

## Cron Jobs / Background Tasks

### Trial expiry reminder

<CodeBlock language="typescript">
{`// Cron: /api/cron/automations
// Schedule: Daily at 6am UTC
// Sends reminder 3 days before trial ends

const threeDaysFromNow = new Date(Date.now() + 3 * 24 * 60 * 60 * 1000);

const tenants = await prisma.tenant.findMany({
  where: {
    trialEndsAt: {
      gte: new Date(threeDaysFromNow.setHours(0, 0, 0, 0)),
      lte: new Date(threeDaysFromNow.setHours(23, 59, 59, 999)),
    },
  },
  include: { users: { where: { role: UserRole.OWNER } } },
});

for (const tenant of tenants) {
  await sendTrialExpiryEmail(tenant.users[0].email, tenant.companyName);
}`}
</CodeBlock>

## Security Considerations

<Callout variant="warning" title="Plan Downgrade">
Downgrading does not delete data. Features are disabled but data remains accessible if plan is re-upgraded.
</Callout>

## Performance Considerations

- Plan tier checks are synchronous (no caching)
- Consider caching plan tier in session for high-traffic routes

## Troubleshooting

**Issue: Feature not unlocking after upgrade**

**Cause:** Session cache stale.

**Fix:** User must log out and log back in to refresh session.
