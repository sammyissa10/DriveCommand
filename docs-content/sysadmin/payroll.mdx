# Payroll Management — Technical Reference

<Callout variant="warning">
Internal engineering documentation. For user-facing docs, see the client Help Center.
</Callout>

## Overview

The Payroll subsystem tracks driver compensation with base pay (salary, hourly, or per-mile), bonuses, deductions, and net pay calculation. Supports flexible pay periods (weekly, bi-weekly, monthly) and auto-calculates miles logged from completed loads.

**Key components:**
- Server actions in `src/actions/payroll.ts`
- PayrollRecord Prisma model
- Miles logged auto-calculation from Load model
- PDF payslip generator

### `createPayrollRecord()`

Creates a payroll record with auto-calculated miles logged.

<CodeBlock language="typescript">
{`export async function createPayrollRecord(
  prevState: ActionState | null,
  formData: FormData
): Promise<ActionState<PayrollRecord>> {
  await requireRole([UserRole.OWNER]);
  const tenantId = await requireTenantId();
  const prisma = await getTenantPrisma();

  const parsed = CreatePayrollRecordSchema.parse({
    driverId: formData.get('driverId'),
    payPeriodStart: formData.get('payPeriodStart'),
    payPeriodEnd: formData.get('payPeriodEnd'),
    basePay: formData.get('basePay'),
    bonuses: JSON.parse(formData.get('bonuses') || '[]'),
    deductions: JSON.parse(formData.get('deductions') || '[]'),
  });

  // Auto-calculate miles logged from completed loads
  const loads = await prisma.load.findMany({
    where: {
      tenantId,
      driverId: parsed.driverId,
      status: LoadStatus.DELIVERED,
      updatedAt: {
        gte: new Date(parsed.payPeriodStart),
        lte: new Date(parsed.payPeriodEnd),
      },
    },
  });

  const milesLogged = loads.reduce((sum, load) => sum + (load.loadedMiles || 0), 0);

  // Calculate totals
  const totalBonuses = parsed.bonuses.reduce((sum, b) => sum + b.amount, 0);
  const totalDeductions = parsed.deductions.reduce((sum, d) => sum + d.amount, 0);
  const grossPay = parsed.basePay + totalBonuses;
  const netPay = grossPay - totalDeductions;

  const payroll = await prisma.payrollRecord.create({
    data: {
      tenantId,
      driverId: parsed.driverId,
      payPeriodStart: new Date(parsed.payPeriodStart),
      payPeriodEnd: new Date(parsed.payPeriodEnd),
      basePay: parsed.basePay,
      bonuses: parsed.bonuses,
      deductions: parsed.deductions,
      milesLogged,
      grossPay,
      netPay,
    },
    include: { driver: true },
  });

  return { success: true, data: payroll };
}`}
</CodeBlock>

**Miles logged calculation:** Sums `loadedMiles` from all loads with `status: DELIVERED` and `updatedAt` within the pay period. User can override after creation.

### `generatePayslipPDF()`

Generates a PDF payslip for the driver.

<CodeBlock language="typescript">
{`export async function generatePayslipPDF(
  prevState: ActionState | null,
  formData: FormData
): Promise<ActionState<{ pdfUrl: string }>> {
  await requireRole([UserRole.OWNER]);
  const tenantId = await requireTenantId();
  const prisma = await getTenantPrisma();

  const payrollId = formData.get('id') as string;
  const payroll = await prisma.payrollRecord.findUnique({
    where: { id: payrollId, tenantId },
    include: { driver: { include: { user: true } }, tenant: true },
  });

  if (!payroll) {
    return { success: false, error: 'Payroll record not found' };
  }

  const pdfBuffer = await renderToBuffer(<PayslipPDF payroll={payroll} />);
  const fileName = \`payslip-\${payroll.driver.user.name}-\${payroll.payPeriodStart.toISOString().split('T')[0]}.pdf\`;
  const s3Url = await uploadToS3(pdfBuffer, fileName, 'application/pdf');

  return { success: true, data: { pdfUrl: s3Url } };
}`}
</CodeBlock>

## Database Schema

<PrismaModelRef model="PayrollRecord" fields={[
  "id: String @id @default(uuid())",
  "tenantId: String (foreign key)",
  "driverId: String (foreign key to Driver)",
  "payPeriodStart: DateTime",
  "payPeriodEnd: DateTime",
  "basePay: Decimal (salary, hourly, or per-mile pay)",
  "bonuses: Json (array of { description: string, amount: number })",
  "deductions: Json (array of { description: string, amount: number })",
  "milesLogged: Int (auto-calculated from loads)",
  "grossPay: Decimal (basePay + totalBonuses)",
  "netPay: Decimal (grossPay - totalDeductions)",
  "createdAt: DateTime @default(now())",
  "updatedAt: DateTime @updatedAt"
]} />

**Indexes:**
- `(tenantId, driverId)` — for driver payroll history
- `(tenantId, payPeriodStart, payPeriodEnd)` — for date range queries

**JSON structure for bonuses/deductions:**

<CodeBlock language="typescript">

## Security Considerations

<Callout variant="danger" title="Critical: Owner-Only Access">
Payroll records are OWNER-only. Managers and dispatchers cannot view payroll. Drivers cannot view their own payroll records (yet).
</Callout>

**Other security notes:**
- PDF payslips should not be stored long-term (regenerate on demand)
- Miles logged can be overridden manually (audit log recommended)

## Performance Considerations

- Miles calculation queries all loads in pay period (can be slow for large fleets)
- Consider caching miles logged after initial calculation
- PDF generation takes ~300ms per payslip

## Troubleshooting

**Issue: Miles logged is 0**

**Cause:** No completed loads in pay period, or loads missing `loadedMiles` field.

**Fix:** Verify loads have `status: DELIVERED` and `loadedMiles` populated.
