# IFTA Reporting — Technical Reference

<Callout variant="warning">
Internal engineering documentation. For user-facing docs, see the client Help Center.
</Callout>

## Overview

The IFTA Reporting subsystem generates quarterly fuel tax reports using GPS-based mileage allocation and fuel purchase tracking. Calculates miles driven per state, fuel purchased per state, and net tax owed/credit.

**Key components:**
- Server actions in `src/actions/ifta.ts`
- GpsReport + FuelLog Prisma models
- State mileage calculation (reverse geocoding GPS pings)
- IFTA tax rate tables (updated quarterly)

### `generateIFTAReport()`

Generates an IFTA report for a quarter and truck(s).

<CodeBlock language="typescript">
{`export async function generateIFTAReport(
  prevState: ActionState | null,
  formData: FormData
): Promise<ActionState<IFTAReport>> {
  await requireRole([UserRole.OWNER]);
  const tenantId = await requireTenantId();
  const prisma = await getTenantPrisma();

  const parsed = GenerateIFTAReportSchema.parse({
    quarter: formData.get('quarter'), // Q1, Q2, Q3, Q4
    year: formData.get('year'),
    truckIds: JSON.parse(formData.get('truckIds')),
  });

  const { startDate, endDate } = getQuarterDates(parsed.quarter, parsed.year);

  // Fetch GPS reports for selected trucks
  const gpsReports = await prisma.gpsReport.findMany({
    where: {
      tenantId,
      truckId: { in: parsed.truckIds },
      timestamp: { gte: startDate, lte: endDate },
    },
    orderBy: { timestamp: 'asc' },
  });

  // Calculate mileage per state using reverse geocoding
  const mileageByState = await calculateMileageByState(gpsReports);

  // Fetch fuel logs for selected trucks
  const fuelLogs = await prisma.fuelLog.findMany({
    where: {
      tenantId,
      truckId: { in: parsed.truckIds },
      date: { gte: startDate, lte: endDate },
    },
  });

  // Aggregate fuel purchases by state
  const fuelByState = aggregateFuelByState(fuelLogs);

  // Calculate tax owed/credit per state
  const taxRates = await getIFTATaxRates(parsed.quarter, parsed.year);
  const stateBreakdown = calculateTaxByState(mileageByState, fuelByState, taxRates);

  const report = await prisma.iftaReport.create({
    data: {
      tenantId,
      quarter: parsed.quarter,
      year: parsed.year,
      truckIds: parsed.truckIds,
      stateBreakdown: stateBreakdown,
      totalMiles: Object.values(mileageByState).reduce((sum, miles) => sum + miles, 0),
      totalFuel: Object.values(fuelByState).reduce((sum, gal) => sum + gal, 0),
      netTax: stateBreakdown.reduce((sum, state) => sum + state.taxOwed, 0),
    },
  });

  return { success: true, data: report };
}`}
</CodeBlock>

### GPS-based mileage calculation

<CodeBlock language="typescript">
{`async function calculateMileageByState(
  gpsReports: GpsReport[]
): Promise<Record<string, number>> {
  const mileageByState: Record<string, number> = {};

  for (let i = 1; i < gpsReports.length; i++) {
    const prev = gpsReports[i - 1];
    const curr = gpsReports[i];

    // Calculate distance between points (haversine formula)
    const distance = calculateDistance(prev.latitude, prev.longitude, curr.latitude, curr.longitude);

    // Reverse geocode to get state
    const state = await reverseGeocode(curr.latitude, curr.longitude);

    mileageByState[state] = (mileageByState[state] || 0) + distance;
  }

  return mileageByState;
}`}
</CodeBlock>

## Code Examples

### Aggregating fuel by state

<CodeBlock language="typescript">
{`function aggregateFuelByState(fuelLogs: FuelLog[]): Record<string, number> {
  const fuelByState: Record<string, number> = {};

  for (const log of fuelLogs) {
    fuelByState[log.state] = (fuelByState[log.state] || 0) + log.gallons;
  }

  return fuelByState;
}`}
</CodeBlock>

## Security Considerations

<Callout variant="warning" title="GPS Data Retention">
GPS reports are stored for 2 years to support IFTA compliance. After 2 years, data is automatically deleted via cron job.
</Callout>

## Performance Considerations

- GPS mileage calculation can process 10,000 pings in ~5 seconds
- Reverse geocoding is cached (state lookup by lat/lng)
- IFTA report generation is CPU-intensive (run async for large fleets)

## Troubleshooting

**Issue: Missing mileage for a state**

**Cause:** GPS tracking disabled or poor signal in rural areas.

**Fix:** Manually add mileage from driver logs or ELD reports.
