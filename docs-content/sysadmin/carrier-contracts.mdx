## Overview

Contract Management handles formal shipper agreements with rate tables and renewal tracking.

**Portal:** Owner

**Plan Tier:** Business+

## Cron Jobs

Renewal reminders sent via `/api/cron/send-reminders` daily at 9am UTC:

<CodeBlock language="typescript">
{`// Check for contracts expiring in 30 days
const expiringContracts = await prisma.contract.findMany({
  where: {
    expirationDate: {
      gte: new Date(),
      lte: addDays(new Date(), 30),
    },
    status: 'ACTIVE',
  },
  include: { customer: true },
});

for (const contract of expiringContracts) {
  await sendContractRenewalEmail({
    customerName: contract.customer.companyName,
    expirationDate: contract.expirationDate,
  });
}`}
</CodeBlock>
