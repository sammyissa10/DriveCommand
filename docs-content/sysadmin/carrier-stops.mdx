<Callout variant="warning">
Internal engineering documentation. For user-facing docs, see the client Help Center.

## Overview

Stop Management provides CRUD for route stops with load linkage.

**Portal:** Owner
**Route:** `/carrier/stops`
**Plan Tier:** Pro+

## Database Schema

<PrismaModelRef model="RouteStop" fields={[
  "id: String @id @default(uuid())",
  "tenantId: String",
  "routeId: String (FK to Route)",
  "loadId: String? (FK to Load)",
  "sequence: Int (stop order in route)",
  "address: String",
  "latitude: Decimal?",
  "longitude: Decimal?",
  "contactName: String?",
  "contactPhone: String?",
  "bolNumber: String?",
  "poNumber: String?",
  "type: StopType (PICKUP | DELIVERY | FUEL | REST)"
]} />

**Bidirectional load linkage:**
- `RouteStop.loadId` → points to Load
- `Load.pickupStopId` → points to RouteStop (pickup)
- `Load.deliveryStopId` → points to RouteStop (delivery)
