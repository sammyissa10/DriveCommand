# Expense Categories — Technical Reference

<Callout variant="warning">
Internal engineering documentation. For user-facing docs, see the client Help Center.
</Callout>

## Overview

The Expense Categories subsystem provides categorization for fleet expenses. Includes default categories (Fuel, Maintenance, Tolls, etc.) and supports custom category creation.

**Key components:**
- Server actions in `src/actions/settings/expenses.ts`
- ExpenseCategory Prisma model
- Default category seeding

## Code Examples

### Seeding default categories

<CodeBlock language="typescript">
{`export async function seedDefaultCategories(tenantId: string) {
  const defaults = [
    { name: 'Fuel', color: '#f59e0b' },
    { name: 'Maintenance', color: '#3b82f6' },
    { name: 'Tolls', color: '#10b981' },
    { name: 'Permits', color: '#8b5cf6' },
    { name: 'Insurance', color: '#ef4444' },
    { name: 'Lease Payments', color: '#6366f1' },
    { name: 'Driver Pay', color: '#ec4899' },
    { name: 'Office Expenses', color: '#14b8a6' },
    { name: 'Other', color: '#6b7280' },
  ];

  for (const category of defaults) {
    await prisma.expenseCategory.create({
      data: {
        tenantId,
        name: category.name,
        color: category.color,
        isDefault: true,
      },
    });
  }
}`}
</CodeBlock>

## Security Considerations

<Callout variant="warning" title="Default Category Protection">
Default categories have \`isDefault: true\` and cannot be deleted. Only custom categories can be deleted.
</Callout>
