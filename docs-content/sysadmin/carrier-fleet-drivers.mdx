### Compliance Status Computation

Compliance dots (green/amber/red) are computed server-side:

<CodeBlock language="typescript">
{`function computeComplianceStatus(driver: Driver): 'ok' | 'warning' | 'critical' {
  const docs = driver.documents;
  const now = new Date();
  const thirtyDaysOut = addDays(now, 30);

  const expiredDocs = docs.filter(d => d.expiryDate && d.expiryDate < now);
  const expiringSoon = docs.filter(d =>
    d.expiryDate && d.expiryDate >= now && d.expiryDate <= thirtyDaysOut
  );

  if (expiredDocs.length > 0) return 'critical'; // Red
  if (expiringSoon.length > 0) return 'warning'; // Amber
  return 'ok'; // Green
}`}
</CodeBlock>
